# 前端美化与同层界面知识

## 一、前端界面正则的推荐写法

### 提高正则容错率

前端界面可能对应于 AI 很复杂的输出格式，但这些格式应该由前端界面的代码通过 `getChatMessages` 获取楼层消息内容后处理，而不应该在酒馆正则里拿 `$1` 等处理。

**前端界面正则唯一要做的是定位前端界面应该在的位置，而不是处理输出数据。**

例如，如果输出格式是：

```text
<status>
心情:→(平静通话)
衣着:居家长T恤
角色阶段:暗中观察
位置:自己房间
</status>
```

前端界面正则只需要定位这一段文本即可：

```yaml
脚本名称: '[界面]状态栏'
查找正则表达式: '<status>.*</status>'  # 正则不需要在意里面具体是什么
替换为: 前端界面的 html 代码块
作用范围:
  - 用户输入
  - AI输出
短暂:
  - 仅格式显示（勾选）
  - 仅格式提示词（不勾选）
```

在代码中，使用 `getChatMessages` 获取整条消息，然后自行解析数据：

```ts
const chat_message = getChatMessages(getCurrentMessageId())[0];
const match = chat_message.message.match(/<status>(.*)<\/status>/);
// 继续拆分数据里的各段文字，从而在前端界面上使用
```

### 避免渲染卡顿

前端界面的渲染过程为：
1. 酒馆正则将内容替换成代码块并渲染出来
2. 酒馆助手将代码块替换为前端界面（仅需几毫秒）
3. 前端界面按代码加载（取决于网络和设备性能）

酒馆渲染代码块这一过程不可避免，前端界面代码越多越卡。

**解决方案**：将 html 转换为链接，正则代码块里只加载链接。这样酒馆需要渲染的代码块内容很少，不会卡顿。

例如正则替换为：
```
\`\`\`
<body>
<script>
$('body').load('https://cdn链接/dist/角色卡名/界面/状态栏/index.html')
</script>
</body>
\`\`\`
```

## 二、同层前端界面方案

玩家只在一个前端界面内进行游玩，不使用酒馆的输入框。

### 核心流程

1. 在前端界面中设计"发送"按钮
2. 通过酒馆助手的 `generate`、`generateRaw` 命令自行请求 AI 回复
3. 如果需要流式显示，监听 `iframe_events.STREAM_TOKEN_RECEIVED_FULLY` 事件获取流式传输文本
4. 依旧使用酒馆的楼层机制记录剧情：
   - 将前端界面正则设为最大深度 `0`
   - 用 `setChatMessages`、`createChatMessages`、`deleteChatMessages` 等函数的 `{ refresh: 'none' }` 参数修改消息楼层但不刷新显示
   - 玩家可以继续游玩界面，剧情记录利用酒馆楼层机制，不需要额外代码

### 关键接口

```ts
// 请求 AI 生成（携带酒馆预设提示词）
const result = await generate({ user_input: '你好' });

// 请求 AI 生成（不携带预设，直接发送）
const result = await generateRaw({ prompt: '...' });

// 创建新楼层但不刷新显示
await createChatMessages([{ role: 'assistant', message: result }], { refresh: 'none' });

// 监听流式 token
eventOn(iframe_events.STREAM_TOKEN_RECEIVED_FULLY, (text) => {
  // text 是当前已接收的完整文本
});
```

## 三、流式楼层界面方案

通过脚本用 jquery 将酒馆楼层显示替换为自定义界面，支持流式传输时实时渲染。

### 核心事件

```ts
// 玩家发送消息，AI 开始生成
eventOn(tavern_events.MESSAGE_SEND, (message_id) => { /* ... */ });

// 流式传输中，每收到一段文本
eventOn(tavern_events.STREAM_TOKEN_RECEIVED, (text) => { /* ... */ });

// AI 回复完成
eventOn(tavern_events.MESSAGE_RECEIVED, (message_id) => { /* ... */ });
```

### 使用编写模板提供的框架

`util/streaming.ts` 中的 `mountStreamingMessages` 函数提供了流式楼层界面框架：

```ts
import { mountStreamingMessages } from '@util/streaming';
import App from './App.vue';

$(() => {
  const { unmount } = mountStreamingMessages(() => {
    return createApp(App).use(createPinia());
  });
  $(window).on('pagehide', () => unmount());
});
```

在 Vue 组件中通过 `injectStreamingMessageContext()` 获取流式上下文：

```ts
import { injectStreamingMessageContext } from '@util/streaming';

const context = injectStreamingMessageContext();
// context.message - 当前消息文本（流式传输中会实时更新）
// context.message_id - 当前消息楼层号
// context.during_streaming - 是否正在流式传输中
```

## 四、修改酒馆提示词

脚本可以监听酒馆的提示词发送事件，自行修改提示词。

### 可监听的事件（按请求生成时先后顺序）

1. `tavern_events.GENERATE_AFTER_COMBINE_PROMPTS`
2. `tavern_events.CHAT_COMPLETION_PROMPT_READY`
3. `tavern_events.GENERATE_AFTER_DATA`（提示词模板、酒馆助手宏发生在这里）
4. `tavern_events.CHAT_COMPLETION_SETTINGS_READY`

### 示例：移除所有 user 提示词

```ts
eventOn(
  tavern_events.CHAT_COMPLETION_PROMPT_READY,
  (event_data: Parameters<ListenerType['chat_completion_prompt_ready']>[0]) => {
    _.remove(event_data.messages, (message => message.role === 'user'));
  },
);
```

### 注意事项

**不要**用 `event_data.chat = [...]` 这种方式（这是创建新数组而非修改原数组）。

**应该**使用：
- lodash 中的原地修改函数（如 `_.remove`）
- 数组的 `splice`、`push` 等原地修改函数

## 五、其他实用功能

### 在脚本中用 jquery 修改酒馆页面

脚本中 jquery 直接作用于酒馆页面（`window.$ = window.parent.$`），可以：
- 修改酒馆网页现有元素
- 添加新界面（悬浮框、外置手机、流式界面等）
- 完全去掉酒馆楼层换成自己的界面

### 执行酒馆 STScript 命令

```ts
// 触发 AI 回复
triggerSlash('/trigger');

// 刷新网页
triggerSlash('/reload-page');
```

命令列表参考 `slash_command.txt` 文件。

### 使用 figma 设计界面

figma 是专业前端原型设计软件，可以：
1. 用预制组件像做 PPT 一样设计界面
2. 配置 figma MCP 让 AI 直接按照设计稿编写代码
3. 使用 figma 的 AI 功能生成更专业的界面设计
