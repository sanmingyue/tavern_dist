# 月之屋剩余任务清单

## 后端核心

- 长期记忆 UI：手动总结、重新总结、编辑大总结、编辑角色记忆、查看已压缩历史。
- 梦呓 / 用户行为画像：分析玩家长期操作习惯、互动偏好、常用表达，再按角色注入。
- 玩家 Persona 系统：给玩家自定义人格资料，支持 AI 分析成结构化画像。
- 工具权限与回滚面板：前端可查看本轮 Agent 改了哪些状态，必要时撤销。
- 更精确 tokenizer：以后可接远端 tokenizer 或原生 BPE/SentencePiece。
- 多存档与角色库管理：同一月之屋后端承载多个角色、多个存档。

## 内容生产

- 角色卡编辑器：角色设定、开场白、世界书、预设一起编辑导出。
- 世界书编辑器：关键词、二级条件、sticky/cooldown/delay、分组竞争可视化。
- 预设编辑器：模型参数、提示词后处理、Agent 模式、长期记忆开关。
- 内容包校验：导入前显示风险、重复项、会覆盖哪些内容。

## Unity 前端

- 游戏 UI：正式聊天界面、角色立绘、地点、状态栏、背包/养成面板。
- 调试面板：提示词预览、世界书命中、Agent 工具结果、长期记忆状态。
- 移动端适配：Android/iOS 输入框、滚动、字体、屏幕安全区。
- 存档管理：新建、读取、复制、导入导出。

## 发布准备

- API Key 安全存储：避免写进可导出的角色包。
- 平台构建：Windows、Android、iOS 分别验证网络、存档路径、字体。
- 错误提示：网络失败、模型空回复、总结失败、取消生成的玩家可读提示。
- 示例项目：一个最小 AIRP 场景，给未来前端作者直接照着接。
