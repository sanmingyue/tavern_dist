# 明月秋青脚本 - 更新日志

## zhino-v4.0.0 / 2026-06-03

### 大版本更新：B3.3

- 新增后台角色行动推演系统：支持手动指定、动态人设角色、世界书角色和路人 NPC 候选，推演结果会结构化注入提示词。
- 重构大总结：改为 Delta 增量存储，只保存新增内容；编辑器仅展示剧情摘要，角色记忆和 NSFW 记忆进入角色库。
- 升级调度系统：大总结、梦呓、情绪和后台推演统一进入串行队列，任务去重并错开触发间隔。
- 增强角色库：新增 NSFW 记忆区块、后台推演行为逻辑树展示，角色列表覆盖未登场但被推演的角色。
- 修复梦呓只分析单个交互角色的问题，提示词明确要求分析近期对话中出现的所有角色。
- 优化数据导入：改用 `safeParse`，区分 JSON 格式错误、字段缺失和 Zod 校验失败。
- 修复大总结倒计时未计入保留楼层偏移的问题。
- 修复楼层隐藏中 `slice(-0)` 导致隐藏失效的问题，并补充诊断日志。
- 后台推演面板支持收起/展开，状态持久化刷新不丢失。
