# 明月秋青 · 智脑脚本

> 为明月秋青预设打造的智能增强系统。自动分析角色、记忆用户行为、精准注入提示词。

## CDN 链接

```javascript
import 'https://testingcf.jsdelivr.net/gh/sanmingyue/tavern_dist@zhino-v4.0.0/dist/明月秋青脚本/index.js'
```

## 使用方法

1. 在酒馆助手的预设脚本库中新建一个脚本
2. 将上面的 import 链接粘贴为脚本内容
3. 启用脚本
4. 点击脚本库中的"智脑面板"按钮打开管理面板

## 功能概览

### 自动运行（无需操作）

| 功能 | 说明 |
|------|------|
| 正文捕获 | 自动捕获每楼AI回复中的正文内容，roll时自动更新 |
| 精准大总结 | 每10楼自动触发，按调色盘体系分析角色，拆分为时间线+角色记忆+动态人设 |
| 梦呓分析 | 大总结后自动分析用户行为模式，生成用户角色的行为习惯档案 |
| 动态人设注入 | 每次AI生成前，自动注入当前在场角色的动态人设变化 |
| 神经链记忆 | 每次AI生成前，自动注入当前在场角色的相关记忆 |
| 梦呓注入 | 每次AI生成前，自动在用户输入中包裹行为模式资料（用户不可见） |
| 楼层隐藏 | 大总结成功后自动隐藏已总结楼层，防止爆TOKEN |

### 手动操作（通过面板）

| 功能 | 说明 |
|------|------|
| 用户人设 | 支持多个人设配置，选择激活哪一个 |
| 角色库管理 | 查看/编辑角色记忆、别名、关键词、动态人设 |
| 梦呓管理 | 查看/编辑用户行为模式、角色交互习惯 |
| 手动大总结 | 不等10楼，随时手动触发 |
| API配置 | 使用酒馆API或自定义API |
| 数据导出/导入 | 备份和恢复所有数据 |

## 前端面板

- PC：点击悬浮按钮打开，可拖动、可调整大小
- 手机：底部弹出面板，下拉手势关闭

4个Tab页：总览 / 角色库 / 梦呓 / 设置

## 工作原理

```
第1-10楼（积累期）：
  └── 捕获正文 + 记录用户输入 + 注入用户人格

第10楼（触发）：
  ├── 精准大总结 → 时间线 + 角色记忆(含别名) + 动态人设
  └── 梦呓分析 → 用户行为模式 + 角色交互习惯

第11楼起（全功能）：
  ├── 动态人设注入（D0，只注入在场角色）
  ├── 神经链记忆（D0，按关系链注入）
  ├── 梦呓注入（包裹用户输入，只注入在场角色的交互模式）
  └── 已总结楼层自动隐藏
```

## 与预设的搭配

- 脚本与 kemini_noass 并行运行，互不干扰
- 动态人设和神经链通过 `injectPrompts` D0 注入
- 梦呓通过修改 `CHAT_COMPLETION_SETTINGS_READY` 中的用户消息注入
- 预设思维链中的"角色运行引擎"会自然消化脚本注入的内容

## 注意事项

- 需要酒馆助手插件支持
- 大总结和梦呓分析会调用AI（使用酒馆当前API），会消耗额外token
- Claude模型会自动检测并调整prefill格式
- 所有数据存储在聊天变量中，切换聊天时数据独立
