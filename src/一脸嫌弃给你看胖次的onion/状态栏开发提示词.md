## 0. MVU 变量结构脚本

**位置**：`src/一脸嫌弃给你看胖次的onion/脚本/变量结构/index.ts`

**注意**：必须和状态栏分开文件夹，否则 pnpm build 会把两个脚本打包成一个文件。

**功能**：注册 MVU schema，让酒馆知道变量结构。

**参考**：
- `src/青春的果实/脚本/变量结构/index.ts`
- `示例/角色卡示例/脚本/变量结构/index.ts`

**变量结构**（对应 `世界书/变量/initvar.yaml`）：

```typescript
import { z } from 'zod';

export const Schema = z.object({
  交易次数: z.coerce.number().prefault(0),
  本周交易次数: z.coerce.number().prefault(0),
  奥妮安存款: z.coerce.number().prefault(500),
  当前场景: z.string().prefault('学校天台'),
  星期: z.string().prefault('星期三'),
  时间段: z.string().prefault('中午'),
  特殊事件: z.string().prefault('无'),
  关系状态: z.enum(['交易对象', '特殊存在', '暧昧', '恋人']).prefault('交易对象'),
});
```

## 1. IF线状态栏

**位置**：`src/一脸嫌弃给你看胖次的onion/状态栏/index.ts`

### 核心功能：IF线生成器

不是生成3段内容，而是生成 **IF线**——和正文"偏差"的平行世界线。

**IF线是什么**：
- 基于当前剧情的某个节点，想象"如果当时做了不同的选择"会怎样
- 可以是幸福的（如果当时没有接受交易，两人以正常方式相识）
- 可以是难过的（如果被同学发现了秘密）
- 可以是温暖的（如果奥妮安的妈妈突然好了，她不再需要钱）
- 可以是甜蜜的（如果他们在交易之前就已经互相喜欢）

**绝对禁止**：
- ❌ NTR（绝对不能出现第三者介入的情感线）
- ❌ 非纯爱（IF线中奥妮安只能和{{user}}产生感情）
- ❌ 黑暗堕落（不能写奥妮安被迫做更过分的事）

**IF线生成提示词方向**：
- 读取当前变量（交易次数、关系状态、当前场景等）
- 根据当前阶段生成合适的IF线分支点
- 用 `generateRaw` 请求AI生成一段200-400字的IF线短文
- IF线的文风要和正文一致（画面感、嫌弃脸、物理事实描写）

### UI设计

**PC端沉浸模式**：
- 参考青春的果实的 `immersive.ts` 方案
- 背景图：`src/一脸嫌弃给你看胖次的onion/图片/ig_0031a886394f7538016a1d6c5b9cac8197964c8b60c7145651.png`（CDN引用）
- 左侧面板显示IF线内容
- 背景覆盖层 z-index:9990, opacity:0.1
- 面板 z-index:9991

**手机端**：
- 内联展开模式（不用 fixed 面板！参考青春的果实踩坑记录）
- 点击按钮 → 在消息楼层内展开IF线内容
- 生成中显示加载动画

**通用UI元素**：
- 奥妮安头像（CDN引用）
- 当前状态显示（交易次数、关系阶段）
- "生成IF线"按钮
- IF线标题（自动生成，如"如果那天没有上天台..."）
- IF线正文区域（带打字机效果）

### 图片资源

### 项目结构

```
src/一脸嫌弃给你看胖次的onion/
├── schema.ts                          # zod 4 变量结构（供脚本和状态栏共用）
├── 脚本/
│   └── 变量结构/
│       └── index.ts                   # 注册 MVU schema（独立打包）
├── 状态栏/
│   ├── index.ts                       # 脚本入口（挂载Vue到最新AI楼层）
│   ├── App.vue                        # 主组件
│   ├── store.ts                       # pinia store（读取MVU变量）
│   ├── immersive.ts                   # PC端沉浸模式
│   ├── components/
│   │   ├── StatusButton.vue           # 触发按钮（显示在楼层末尾）
│   │   ├── IfLinePanel.vue            # IF线内容面板
│   │   └── IfLineGenerator.vue        # IF线生成中的加载状态
│   └── ifline/
│       ├── generator.ts               # AI生成IF线逻辑（generateRaw）
│       ├── prompts.ts                 # IF线生成提示词（按阶段不同）
│       └── types.ts                   # 类型定义
├── 图片/
│   └── ig_0031a886394f7538016a1d6c5b9cac8197964c8b60c7145651.png  # 背景图源文件
└── 世界书/                             # 已完成，不需要修改
```

### 关键技术点

1. **脚本入口**：参考青春的果实，挂载到最新AI楼层的 `.mes_block`
2. **沉浸模式**：用 jQuery 在 body 上创建 DOM，不走 Vue 组件
3. **手机端**：内联展开，不用 fixed 面板
4. **IF线生成**：用 `generateRaw` 调用AI，提示词包含当前变量状态和角色人设
5. **图片**：CDN引用，不内联base64

### IF线生成提示词模板

```typescript
const prompt = `你是一个专业的AIRP作者。现在需要你为角色"奥妮安"生成一段IF线（平行世界线）。

当前状态：
- 交易次数：${tradeCount}
- 关系状态：${relationship}
- 当前场景：${scene}

IF线要求：
- 基于当前剧情节点，想象一个不同的选择导致的平行展开
- 200-400字
- 保持角色性格一致（嫌弃脸永远是核心）
- 画面感优先，用物理事实描写
- 可以是幸福的、温暖的、遗憾的、甜蜜的
- 绝对不能出现NTR或非纯爱内容
- 奥妮安只能和{{user}}产生感情

请直接输出IF线正文，不要加标题或说明。`;
```

## 4. 开发顺序

1. 先写 `schema.ts`（变量结构定义）
2. 写 `脚本/变量结构/index.ts`（注册schema）
3. 写 `状态栏/store.ts`（读取变量）
4. 写 `状态栏/ifline/generator.ts` + `prompts.ts`（IF线生成逻辑）
5. 写 `状态栏/components/`（UI组件）
6. 写 `状态栏/App.vue`（主组件）
7. 写 `状态栏/immersive.ts`（PC沉浸模式）
8. 写 `状态栏/index.ts`（入口，挂载逻辑）
9. `pnpm build` 验证
10. 推送CDN，发CDN链接
