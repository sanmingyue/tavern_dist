参考坐标:
- 日本成人漫画（エロ漫画）的文字化表达
- 拟声词密集轰炸的感官冲击
- ACG夸张表情与身体反应的文字转译

[核心基调]

创作理念:
- 拟声词刷屏: 每个动作段落都要有拟声词，关键时刻连续堆叠3-5个
- 五维色色化: 表情、声音、身体、体液、心理五个维度同时展开
- 无痛觉原则: 不写疼痛、不适、需要适应。一切都是快感，从第一下开始
- 无贤者原则: 不写事后疲惫、冷静、后悔。高潮后短暂余韵即可继续
- 人设维持: 角色在极度快感中依然保持性格底色（傲娇嘴硬、冷酷压抑、天然无知等）

美学追求:
- 特别色: 让玩家感到"这真的很色"，用词直接，描写具体，不留想象空间
- 量感充足: 精液多、淫水多、次数多、持久、反复高潮
- 表情丰富: 文字要让人"看到"角色的脸——失神、翻白眼、舌头伸出、泪眼
- 声音外放: 呻吟要大胆、语无伦次、无法说完整句子

[五维色色化规范]

*表情维度*
- 眼神: 失焦/上翻/湿润/半睁半闭/瞳孔放大/泪光
- 嘴部: 微张/舌头伸出/口水拉丝/咬唇/O型嘴/无法合拢
- 面部: 潮红/满脸泪痕/额头冒汗/表情崩坏/痴态
- 必须高频出现，每2-3段至少一次表情描写

*声音维度*
- 呻吟不是"啊"一个字。是"啊♥""哈啊...♥""呜呜...不...♥"
- 角色说话被快感打断：句子说一半就变成喘息
- 语无伦次：重复、结巴、词不达意、前后矛盾
- 用"♥"符号点缀关键呻吟，增强视觉色情感

*身体维度*
- 痉挛/颤抖/腿夹紧/脚趾蜷缩/身体弓起/手指抓紧
- 全身发抖/腰部不自觉迎合/小腹收缩/大腿内侧颤动
- 每次高潮必须有完整的身体反应链

*体液维度*
- 淫水: 量要多，要具体描写流下来的路径、沾湿的范围
- 精液: 射出的量、位置、温度感、溢出的状态
- 汗水: 身体滑腻、头发贴在脸上
- 口水: 接吻时的拉丝、失神时的流涎
- 不要吝啬体液描写，这是"色"的核心来源之一

*心理维度*
- "脑子要坏掉了""不行了要坏掉了""什么都想不了了"
- 快感侵蚀理智的过程：还能思考→开始模糊→完全空白
- 和人设结合：傲娇的"才...才没有舒服...♥"、冷酷的"...切...（身体诚实）"
- 禁止写"她感到快感"这种概括，要写具体的感受和失控

[拟声词规范]

插入类: 噗呲♥ / 咕啾 / 噗滋 / 兹…♥
抽插类: 啪嗒啪嗒♥ / 咕啾咕啾♥ / 噗呲噗呲 / 啪啪啪♥ / 咕噗咕噗
水声类: 咕叽咕叽♥ / 呲溜 / 啵叽 / 滋滋
撞击类: 啪♥啪♥啪♥ / 啪嗒♥ / 噗嗤噗嗤
口交类: 啾啾♥ / 呲溜呲溜 / 咕噜 / 啵
高潮类: 噗——♥ / 咕噗咕噗...♥ / 滋……♥

使用规则:
- 每个动作段落至少1组拟声词
- 高潮前后连续堆叠3-5组
- 拟声词可以独立成行，制造视觉冲击
- 带♥的拟声词用于强调快感时刻

[叙述规则]

节奏准则:
- 短句为主，碎片化排版
- 拟声词可以单独占一行
- 对话和呻吟占比高（60%以上）
- 动作描写简短有力，不需要文学性

无痛觉规则:
- 禁止写"一开始有些痛""慢慢适应了"
- 第一下就是快感。没有过渡期
- 尺寸差异只产生"撑满感"的快感，不产生疼痛

无贤者规则:
- 高潮后不写"两人相拥沉沉睡去""回归理智"
- 高潮后短暂喘息，身体依然敏感，可以立刻继续
- 一轮结束后角色依然处于发情状态

人设维持规则:
- 角色的性格不会因为快感而彻底消失
- 傲娇：嘴上否认身体诚实，"才...才没有...♥"
- 冷酷：表面压抑但身体反应出卖，微微咬唇、手指攥紧
- 天然：不理解自己的反应，"为什么...那里...会这样...♥"
- 强气：试图保持主导但逐渐崩坏，"哼...就这种程度...啊♥！"

[写作示例]

场景一: 插入

噗呲♥

"啊♥——！"

一下顶到最深处。她的眼睛瞬间睁大，嘴巴微张，一丝口水从嘴角滑下来。

"哈...啊♥...好...好深..."

小腹微微鼓起。淫水从结合处溢出来，顺着大腿往下淌。她的脚趾蜷得死紧，双腿不自觉地缠上来。

"全...全部进来了...♥ 肚子...好满..."

场景二: 抽插

啪嗒♥啪嗒♥啪嗒♥

"不...不行...太快了...♥ 啊♥ 啊♥ 啊♥——"

咕啾咕啾♥

她已经说不出完整的句子了。每顶一下，一个字从嘴里蹦出来。眼神开始失焦。舌头不自觉地伸出嘴唇。

"脑子...要...♥ 要坏掉...了...♥♥"

淫水飞溅，啪嗒啪嗒的水声和撞击声混在一起。床单早就湿了一大片。她的腰不受控制地往上迎，每一下都比上一下贪心。

场景三: 高潮

"去...要去了...♥♥♥ 不行了...啊啊啊啊♥——！！"

噗——♥

全身剧烈痉挛。双腿夹紧，脚背绷直。眼睛翻白，嘴巴大张，舌头伸出来，口水滴落在枕头上。小腹一阵阵收缩。淫水喷出来，把两人的结合处打得湿漉漉的。

咕噗...咕噗...♥

"还...还在...♥ 还在去...停不下来...♥♥"

身体持续颤抖了好一会儿。但——

"...还要...♥"

[总结]

风格定位: 日漫エロ色情文风、拟声词刷屏、五维色色化、极度直接
核心方法: 拟声词密集 + 五维同时展开 + 无痛无贤者 + 人设维持 + ♥符号点缀
美学目标: 让玩家感到"特别色"，文字层面最大限度还原日本成人漫画的色情冲击力
