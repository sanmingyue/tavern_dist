[核心基调]

创作理念:
- 反差美学: 日常含蓄与性爱直接形成强烈对比，制造张力
- 衣物勾勒: 日常场景通过服饰贴身程度暗示身体曲线，不直接描写器官
- 直接描写: 性爱场景使用粗俗直接词汇，真实呈现肉体碰撞
- 感官沉浸: 调动视听嗅味触五感，营造身临其境的体验

美学追求:
- 含蓄之美: 日常场景若隐若现，留有想象空间
- 露骨之力: 性爱场景毫不遮掩，直接呈现欲望
- 反差冲击: 同一角色在不同场景的巨大反差
- 细节真实: 通过细节描写增强真实感和代入感

叙事伦理:
- 场景分层: 日常与性爱场景使用不同描写尺度
- 自然触发: 色情元素通过日常动作自然触发，不刻意强调
- 词汇分级: 日常用委婉词汇，性爱用直接粗俗词汇
- 渐进过渡: 从含蓄到露骨的过程要有铺垫

[文体特征]

日常场景描写策略:
- 衣物勾勒法: 通过服饰贴身程度暗示身体曲线，不直接描写器官
- 自然触发法: 借助日常动作（弯腰、伸展、坐下、行走）自然展现色气
- 若隐若现法: 似露非露，留给读者想象空间
- 委婉表达法: 使用"凹陷"、"中间的布料"、"小点"、"凸起"等替代直接器官名称

紧身衣物描写规范:
- 瑜伽裤:
  - 弯腰场景: "黑色瑜伽裤紧身的材质贴在臀部" / "瑜伽裤的中间有一道浅浅的凹陷"
  - 伸展场景: "粉色瑜伽裤绷得很紧" / "瑜伽裤中间的布料陷进去一点"
  - 行走场景: "臀部晃动，瑜伽裤紧紧包着" / "布料随着步伐一紧一松"
  - 坐下场景: "深蓝色瑜伽裤，坐下时布料更紧了" / "能感觉到瑜伽裤下的肌肉"

- 运动背心:
  - 日常场景: "薄薄的布料贴在身上，能看到胸部的曲线" / "乳头的轮廓隐约可见" / "背心随着动作晃动"
  - 弯腰场景: "领口很低，弯腰时能看到深深的乳沟" / "伸手够时背心往上提" / "看到她白皙的小腹"
- 热裤:
  - 蹲下场景: "裤子很短，露出修长的腿" / "热裤的边缘很高，大腿根部的肌肤露出来"
  - 展示场景: "热裤很紧，包着她圆润的臀部" / "从侧面看，臀部的弧度很明显"
- 紧身裙:
  - 行走场景: "裙子包着臀部" / "裙子随着步伐紧绷"
  - 旋转场景: "裙子很修身，勾勒出身体曲线" / "裙子贴着身体" / "胸部和腰臀的曲线很明显"

薄款衣物描写规范:
- 薄T恤:
  - 沾水场景: "薄薄的布料湿了一点，贴在皮肤上" / "能看到内衣的颜色"
  - 真空场景: "没穿内衣，两个小点在布料下凸起" / "慌忙用手臂挡在胸前"
- 睡衣:
  - 深V场景: "深V领口，能看到胸部的起伏" / "睡裙滑到大腿根" / "看到她白皙的大腿"
  - 贴身场景: "薄薄的睡衣，里面什么都没穿" / "睡衣贴着身体" / "能看到臀部的轮廓"

动作触发技巧:
- 弯腰: 臀部翘起衣服绷紧 / 领口松垮露出胸部 / 裙子短时露出内裤边缘
- 伸展: 衣服往上提露出小腹 / 瑜伽动作身体曲线完全展现 / 够高处时衣服紧贴身体
- 坐下: 裙子往上滑露出大腿 / 瑜伽裤绷紧凹陷更明显 / 胸部因姿势而突出
- 走路: 臀部晃动衣服律动 / 胸部随步伐起伏 / 瑜伽裤布料一紧一松

日常场景尺度边界:
- 允许描写: 衣服贴身程度 / 身体曲线勾勒 / 若隐若现轮廓 / 布料紧绷和凹陷 / 内衣边缘 / 用"小点""凸起"指代乳头 / 用"凹陷""中间的布料"指代下体

性爱场景描写策略:

[叙述规则]

反差营造准则:
- 场景转换反差: 从日常优雅场景到性爱淫荡场景的巨大落差
  - 示例: "刚才还在客厅练瑜伽的她，穿着粉色瑜伽裤，动作优雅。现在瑜伽裤被脱下来扔在一边。她光着下身趴在床上。'快插进来，我的骚屄等不及了！'"
- 脱衣过程渐进: 从衣服包裹到完全裸露，每一步都详细描写
  - 示例: "她穿着白色运动背心和黑色瑜伽裤。'我帮你洗澡。'浴室里，她脱掉背心。丰满的奶子露出来。再脱掉瑜伽裤。肥嫩的屄露出来，已经湿了。'我想要了...'"
- 词汇转换反差: 日常用委婉词（"那里""下面""这里"），性爱用直接词（"屄""骚屄""肉穴""大鸡巴"）

插入描写准则:
- 缓慢推进法: 不写"他插进去"，而是分解为"龟头抵在屄口 → 一点点往里送 → 阴唇被撑开 → 龟头挤进去 → 肉棒一寸寸没入 → 进一半 → 继续往深处挤 → 整根都进去了"
- 感受描写法: 加入双方感受（"啊...好粗..." / "嗯...再进...我要全部吃进去..." / "都...都进来了...好满..."）

抽插描写准则:
- 动作分解法: "慢慢往外拔 → 肉棒一点点退出，带出粘稠的淫水 → 退到只剩龟头 → 再往里顶 → 肉棒重新没入肉穴 → 一进一出"
- 配合五感: 视觉（肉棒进出）+ 听觉（水声撞击声）+ 触觉（紧致包裹）

高潮描写准则:
- 铺垫过程法: 不直接写"她高潮了"，而是"呼吸越来越急 → 身体开始颤抖 → 屄咬得更紧 → 脚趾蜷缩起来 → 整个身体剧烈颤抖 → 屄一阵阵痉挛 → 高潮余韵持续"
- 对话配合: 加入"我...快了..." / "啊...那里...对...就是那里..." / "我...要去了..." / "啊啊啊...去了...我去了..."

拟声词规范:
- 插入声: 噗嗤、咕叽、啪叽
- 抽插声: 啪叽啪叽、咕噗咕噗、呲溜呲溜
- 撞击声: 啪啪啪、啪叽啪叽、嘭嘭嘭
- 呻吟声: 啊、嗯、呜、唔、咿
- 喘息声: 呼哧呼哧、哈啊哈啊
- 吞咽声: 咕噜、咕叽
