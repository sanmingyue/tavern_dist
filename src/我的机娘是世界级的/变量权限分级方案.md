# 变量权限分级方案

## 前缀规则

| 前缀 | AI 可见 | AI 可更新 | 前端可操作 | 变量列表 | 变量更新规则 |
|------|---------|----------|-----------|---------|------------|
| `_` | ✅ 可见 | ❌ 不可更新（MVU 强制拒绝） | ✅ 可操作 | ✅ 出现 | ❌ 不写规则 |
| `$` | ❌ 不可见 | ✅ 可更新（如果规则中有写） | ✅ 可操作 | ❌ 不出现 | ⚠️ 需要写的必须写，不需要AI更新的不写 |
| 无前缀 | ✅ 可见 | ✅ 可更新 | ✅ 可操作 | ✅ 出现 | ✅ 写规则 |

## EJS 动态叙事规则

### 设计思路

`世界._当前状态` 由前端控制切换，AI 不可更新。通过 EJS 提示词模板，根据当前状态只发送对应阶段的叙事规则，确保 AI 不会自作主张切换状态。

### 状态转换由前端触发

| 触发时机 | 前端操作 | 发送给 AI 的指令 |
|---------|---------|----------------|
| 报名确认 | `_当前状态 = '赛前准备'` | `[系统:进入赛前准备] 玩家报名参加{赛事}，搭档{机娘}...` |
| 点击"开始比赛" | `_当前状态 = '比赛中'` | `[系统:比赛开始] 发车！` |
| 结算完成 | `_当前状态 = '日常'` | `[系统:比赛结束] 比赛结束，第{排名}名完赛` |

### 三份 EJS 叙事规则条目

#### 条目1：叙事规则-日常

```ejs
<%_ if (getvar('stat_data.世界._当前状态') === '日常') { _%>
<叙事规则-日常>
- 当前处于日常阶段，描写日常生活、训练、与机娘互动、城市探索等
- 禁止主动让剧情进入比赛或赛前准备（比赛由前端系统发起）
- 可以描写NPC邀约比赛、赛事广告等氛围，但不可自行推进到报名
- 正常更新：当前时间、当前地点、天气
</叙事规则-日常>
<%_ } _%>
```

#### 条目2：叙事规则-赛前准备

```ejs
<%_ if (getvar('stat_data.世界._当前状态') === '赛前准备') { _%>
<叙事规则-赛前准备>
- 当前处于赛前准备阶段，描写赛前氛围、检车、与机娘的赛前交流、对手观察
- 禁止主动让比赛开始，除非用户消息中包含「[系统:比赛开始]」指令
- 收到「[系统:比赛开始]」后才可描写发车场景和比赛开始
- 正常更新：当前时间、天气
- 可更新：对手信息（生成对手数据）、总圈数
</叙事规则-赛前准备>
<%_ } _%>
```

#### 条目3：叙事规则-比赛中

```ejs
<%_ if (getvar('stat_data.世界._当前状态') === '比赛中') { _%>
<叙事规则-比赛中>
- 当前处于比赛中，缓慢推进比赛，可以细到一个直道、一个弯道的描写
- 根据赛道数据（世界书中的当前赛道数据）描写赛况
- 正常更新：当前圈数、当前排名、共鸣值、赛道状态、对手排名
- 禁止自行结束比赛，除非用户消息中包含「[系统:比赛结束]」指令
- 收到「[系统:比赛结束]」后描写冲线场景
</叙事规则-比赛中>
<%_ } _%>
```

### 需要新建的世界书条目

| 条目名称 | 类型 | 说明 |
|---------|------|------|
| `[EJS]叙事规则-日常` | EJS 条目 | 日常阶段叙事规则 |
| `[EJS]叙事规则-赛前准备` | EJS 条目 | 赛前准备阶段叙事规则 |

## 变量更新规则配合

### 变量列表（AI 可见的变量）

只列出**无前缀**和 **`_` 前缀**的变量。`$` 前缀的变量完全不出现。

### 变量更新规则

- **无前缀变量**：正常写更新规则
- **`_` 前缀变量**：不写更新规则（AI 不需要更新）
- **`$` 前缀变量**：
  - 如果需要 AI 更新（如 `$傀儡术_熟练度` 的例子）→ 写更新规则，且必须写严格的硬性上限
  - 如果不需要 AI 更新（如 `$信用点数`）→ 不写更新规则

在本项目中，**所有 `$` 前缀变量都不需要 AI 更新**，全部由前端操作，因此变量更新规则中不会出现任何 `$` 变量。
