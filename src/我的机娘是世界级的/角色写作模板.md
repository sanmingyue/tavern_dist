# 机娘角色写作模板

## 核心原则
**我们不写无敌的角色，我们写有故事的角色。**

每个机娘都有明显的短板，都有被这个世界伤害过的痕迹。她们的魅力不来自完美，来自不完美中那一点不肯熄灭的东西。

## 结构（按顺序）

### 1. 基础信息
- 名称
- 原型（对应的真实赛车）
- 发动机（与角色故事深度关联）
- 车身色
- 身高
- 外貌（口语化描写，不是参数罗列）
- 核心（详见下方核心写作要求）
- 共鸣技能名

### 2. 核心写作要求
核心是机娘的心脏，在胸口正中。每个机娘的核心都应该有：
- **外观**：与原型赛车特征强关联的视觉设计
- **被压抑的感觉**：核心不是安静的，即使在日常也有对应引擎/机械的低频存在感
- **情绪联动**：情绪波动时核心的视觉/触觉变化
- **共鸣触发**：车手触碰核心时的爆发描写——从被压抑到释放
- **私密性**：核心对机娘的个人意义，不仅是"机娘通用规则的私密"，而是和这个角色的故事绑定的特殊意义

### 3. 背景
- 口语化叙述，不用数据描述能力
- 写她经历过什么，不要写她的参数是多少
- 重点是"为什么她变成了现在这样"
- 必须有明显的短板和因此受到的伤害

### 4. 性格调色盘
格式：
```
性格调色盘: 人的性格就像调色盘，XX是底色，XX是主色调，由多种性格衍生组合而成才是活生生的人
主色调: XX
底色: XX
性格点缀: XX
```

每个性格写3~5条衍生，衍生要求：
- 用调色盘教程的手写风格
- 每条衍生展开一个具体场景或行为
- 给出行为背后的原因（不是AI式分析，是人话）
- 性格之间要有对冲和矛盾
- 不使用数据化表述

### 5. 三面性
判断标准：角色在不同场景下行为模式是否有**根本性切换**。如果没有就不写。

每张面包含五个部件：
- 触发条件
- 能量状态
- 语料（具体台词，口语化，不能有数据/参数类表述）
- 身体行为模式
- 功能

必须写：
- 面与面之间的过渡（不是开关切换，是渐变）
- 渗透（一张面运行中其他面的泄漏）

### 6. 二次解释
格式："对角色的理解与思考"

要写的内容：
- 保护色/表面性格的本质
- 核心特征（引擎/发动机等）的心理地位
- 共鸣技能的情感含义（不是技术描述）
- 第一次共鸣的完整情感场景（重点！要能让玩家和角色一起被打动）
- 短板/恐惧和自弃的关系
- 角色最大的反差点

## 禁止事项
- 禁止用数值描述机娘能力（如"加速度99"），用口语化感受代替（如"起步快得离谱"）
- 禁止AI化/机器人化表述（参考机娘人格准则）
- 禁止写无敌角色——每个角色必须有明显短板
- 禁止语料中出现数据/参数类用语
- 禁止把二次解释的内容写进三面性（三面性只写"怎么运作"，不写"为什么"）
