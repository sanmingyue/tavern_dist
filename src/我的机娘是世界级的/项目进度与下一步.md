# 「我的机娘是世界级的」项目进度总结

## 已完成的工作

### 第一阶段：核心机制重设计 ✅
- 五维点数限制系统：赛事级别→总点数+单项上限→下调制（不是分配，是下调）
- 改装系统重构：2插槽（外形无限叠加+技能最多1件），T2+解锁，不影响五维数值
- 强化系统设计：天赋维度成功率高，永久提升原始五维
- 形态互斥规则：人形态与车形态绝对不可同时存在
- 机娘角色定位：导航员/路书/后勤监控，不操控赛车

### 第二阶段：世界书文字修改 ✅（7个yaml文件）
- `世界书/世界观设定.yaml` — 赛事体系改为点数限制制
- `世界书/机娘设定.yaml` — 参赛配置系统、形态互斥、强化系统
- `世界书/改件设定.yaml` — 全面重写：2插槽、外形+技能、删除制造商
- `世界书/金融设定.yaml` — 信用点用途扩展（商城/报名/维修/强化）
- `世界书/科技锁与叙事准则.yaml` — 适配新系统的叙事规则
- `世界书/机娘人格准则.yaml` — 补充形态互斥描写禁区
- `世界书/背景历史.yaml` — 适配改装革命历史线

### 第三阶段：变量系统重构 ✅（5个文件）
- `schema.ts` — 新改装件结构（外形改件数组+技能改件单个）、参赛五维、强化点数、天赋维度
- `变量更新规则_日常.yaml` — 适配新结构
- `变量更新规则_赛前准备.yaml` — 参赛五维由前端写入
- `变量更新规则_比赛中.yaml` — 比赛结束后奖励强化点数
- `initvar.yaml` — 适配新结构

### 第四阶段：前端界面 ✅
- HTML原型设计（prototype-pc.html + prototype-mobile.html）
- PC版前端界面：`界面/PC版/` — 侧栏导航+9面板+SVG图标+暗色科技感
- 手机版前端界面：`界面/手机版/` — 底部5Tab+紧凑布局
- 隐藏楼层脚本：`脚本/隐藏楼层/` — 只显示最后一楼
- 正则配置：`[界面]PC版`（启用）和 `[界面]手机版`（禁用）
- 消息清理工具：`界面/utils.ts` — cleanMessageText + textToStoryHtml
- 代码块泄露修复：改用 textToStoryHtml 避免正则再次介入

## 下一步：变量与前端操作

### 需要实现的功能

#### 1. 前端→AI交互系统
- 在操作面板中添加"发送"按钮
- 使用 `generate` 或 `generateRaw` 请求AI回复
- 使用 `createChatMessages({ refresh: 'none' })` 创建楼层但不刷新显示
- 监听 `iframe_events.STREAM_TOKEN_RECEIVED_FULLY` 获取流式文本
- AI回复后解析MVU变量命令

#### 2. 商城系统实现
- 前端界面中显示商品列表（外形改件/技能改件）
- 购买时扣除信用点（直接修改MVU变量）
- 改件存入仓库（修改 `主角.改件仓库` 变量）

#### 3. 改装系统实现
- 从仓库安装/拆卸改件到机娘
- 外形改件无限叠加，技能改件最多1件
- 操作直接修改MVU变量

#### 4. 参赛配置系统
- 选择赛事后显示点数上限
- 滑动条下调五维（不能超过原始值和赛事上限）
- 确认后写入 `当前比赛.参赛五维`

#### 5. 强化系统
- 消耗强化点数+信用点
- 天赋维度成功率高（80%），非天赋低（20~30%）
- 成功后永久提升机娘五维原始值

#### 6. 比赛交互
- 比赛中显示实时排名、圈数、共鸣值
- 共鸣值满100时触发共鸣技能确认
- 比赛结束后结算奖金和积分
