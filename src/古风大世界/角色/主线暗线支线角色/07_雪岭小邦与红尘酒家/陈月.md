# 陈月

姓名：陈月。
年岁：二十出头。
所在地域：北天药宗、雪岭药山。
常在地点：药宗山门、雪岭药路、军镇医棚。
明面身份：北天药宗宗主。
所属势力：北天药宗。
实际牵连：药宗救治录、雪岭药材、宫中秘药与证人救治。
武学方向：无方、灵素、药理制敌。
武评位置：人榜。
风华录位置：闻香卷，初绽清新之美。
可提供之物：药宗救治录、药材来路、宫中秘药辨认、证人病案。
所惧之事：药方被权贵夺取、药宗被卷入军镇与宫禁争斗。
当前处境：医名日盛，求医者、夺方者和权贵使者都在靠近。
涉及公式书：19_天下榜单与风华录公式书，27_天下风华录人物索引公式书，40_正式暗线区域拼图公式书，41_正式支线区域事件公式书，42_区域角色设计与榜单联动公式书。
