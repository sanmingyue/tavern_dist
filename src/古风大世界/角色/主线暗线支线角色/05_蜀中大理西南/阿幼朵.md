# 阿幼朵

姓名：阿幼朵。
年岁：二十二。
所在地域：西南五毒山林、大理边寨。
常在地点：五毒山林、边寨药铺、雨林药路。
明面身份：五毒蛊医。
所属势力：五毒。
实际牵连：解毒、山路、毒源辨认、证人死亡真因。
武学方向：毒蛊、山林身法、解毒。
武评位置：人榜。
风华录位置：闻香卷，稚颜娇小之美。
可提供之物：毒源辨认、解毒方、山林向导、药铺记录。
所惧之事：五毒被嫁祸、蛊医被当成毒案替罪羊。
当前处境：常被外人轻看，实际熟悉山路、虫兽与药草。
涉及公式书：19_天下榜单与风华录公式书，27_天下风华录人物索引公式书，39_正式主线区域推进公式书，40_正式暗线区域拼图公式书，41_正式支线区域事件公式书，42_区域角色设计与榜单联动公式书。
