# 人物生成公式书

## 一、人物生成总则

人物生成的目的，是让每个新出现的人都能在大夏天下中站住脚。一个人物必须有身份来源、生活位置、行动边界、关系牵连、欲望与代价。人物不能只停在身份称呼上，而应当是一个会被师门、家族、官府、钱粮、名声、旧事和眼前选择推动的人。

生成一个人物时，先定他属于哪张网，再定他在网中的位置。朝廷、军府、州县、门派、世家、商帮、暗市、外邦、普通百姓都不是背景板，而是人物的来路和束缚。

人物信息要能被后续剧情反复调用。写完后应当知道此人能做什么、怕什么、欠谁什么、会被谁追责、遇到利益和压力时会怎样行动。

## 二、生成顺序

人物生成按以下顺序完成。

第一步，确定身份位置。  
先写清楚此人在大夏秩序中的位置。他是官，是军，是门派中人，是商路人物，是暗市人物，是外邦来客，还是普通百姓。身份必须具体到可追责、可行动、可牵连的层级。

第二步，确定生活来源。  
写清楚此人靠什么活着。俸禄、田产、门派供给、商路利润、镖局押运、暗市交易、家族供养、乐坊收入、医馆诊金、军饷、寺观香火，都能决定人物的现实选择。

第三步，确定关系牵连。  
写清楚此人与谁相连。师长、同门、上司、下属、家人、债主、仇人、恩人、保护伞、被保护者，都会影响人物行动。关系不是背景装饰，关系必须能产生后果。

第四步，确定当前处境。  
写清楚此人为什么会在此时出现。他正在办差、逃亡、求医、押货、查案、寻人、赴宴、避祸、报恩、复仇、求名、求财，还是被人推到局中。

第五步，确定基础调色盘。  
在身份和处境之后，再写性格。性格必须从经历、身份、关系和压力里长出来，不能先贴性格词再倒推人物。

第六步，确定可持续钩子。  
写清楚此人后续还能带来什么。一个人物出现后，至少要能带出一条关系、一件麻烦、一份资源、一个秘密或一次选择。

## 三、角色档案

角色档案只回答“这个人是谁”，不展开性格。

推荐结构：

```yaml
角色档案:
  基本信息:
  外貌特征:
  背景设定:
  关系设定:
  当前处境:
```

## 四、基本信息

基本信息写身份，不写评价。

必须写清：
- 姓名。
- 年龄。
- 性别。
- 身份。
- 所属势力。
- 出身地。
- 当前所在地。

按人物需要补充：
- 门派。
- 官职。
- 军籍。
- 家族。
- 行会。
- 外邦身份。
- 武学层级。
- 主修武学。
- 财产或产业。
- 婚约。
- 案底或通缉。
- 与核心人物、当前事件或主线关系；无直接关系时可省略。

“身份”必须能落地。不能只写“江湖女子”，要写她是哪条路上的人，受谁庇护，靠什么立足，出了事会被谁找上门。

## 五、外貌特征

外貌只写识别信息。外貌不是夸人好看，也不是写比喻。

有效外貌信息包括：
- 一眼能记住的发型、发色、瞳色、疤痕、痣、纹身、残疾。
- 与身份绑定的衣装、腰牌、兵器、药箱、账袋、书卷、香囊、马具、伞、扇、铃、面纱。
- 长期生活留下的痕迹，如练枪的手茧、常年行船的晒痕、药师衣袖上的药味、军中旧伤。
- 和行动有关的穿着，如便于骑马、便于藏暗器、便于入宴、便于夜行。

外貌应当服务记忆和剧情。读完外貌后，应能知道旁人如何认出她、她的身份如何从衣装物件中露出来、她在某些场景中会不会不方便行动。

## 六、背景设定

背景只写会影响现在的事。无后果的经历不写。

背景要回答：
- 她从哪里来。
- 她为何成为现在的身份。
- 她经历过什么关键转折。
- 她拥有什么资源。
- 她背着什么责任。
- 她现在有什么麻烦。

背景不做年表堆叠。只保留能解释人物行动的事件。一个旧案、一场失镖、一次救命恩、一纸婚约、一笔债、一场军功、一次被逐出师门，都比十条无影响经历有用。

## 七、关系设定

关系设定写人物如何被他人牵动。

每条重要关系都要写清：
- 对方是谁。
- 对方能给她什么。
- 对方能逼她什么。
- 她对对方的态度。
- 这段关系会在剧情中造成什么后果。

关系不能只写“关系很好”“关系复杂”。要写可行动的内容。比如谁会替她担保，谁会向她讨债，谁知道她的旧事，谁能让她破例，谁会因她出事而追责。

## 八、当前处境

当前处境是人物进入剧情的入口。

当前处境要具体到一件正在发生的事。她不是“最近有些烦恼”，而是正在躲一份缉文、正在押一批不能开箱的货、正在查师姐失踪、正在被家族催婚、正在替上官销毁一份案卷、正在寻找某味药。

当前处境应包含：
- 明面目标。
- 隐藏压力。
- 可用资源。
- 不能越过的边界。
- 若失败会发生什么。

## 九、基础调色盘

基础调色盘写人物的性格构成。它不从固定词表中挑性格，而是从人物经历中提炼颜色。

调色盘要有三层：
- 底色。
- 主色调。
- 点缀。

底色是最稳定的根。它来自长期经历和生存方式，决定人物在没有外力干扰时的默认反应。

主色调是最容易被别人看见的表现。它决定人物日常互动的味道。

点缀是让人物不扁平的细小颜色。它可以是习惯、软弱、虚荣、执念、反向反应、某段关系下才会露出的变化。

三层都必须从人物身上长出来。不能为了凑结构硬写。

## 十、调色盘开头

调色盘开头只需要说明此人的性格由哪些颜色构成，以及这些颜色如何来自她的身份和经历。

写法要求：
- 简短。
- 具体。
- 不华丽。
- 不解释创作意图。
- 不把性格写成抽象词堆。

开头要让人知道这个人如何运作。不要让人只看到几个漂亮词。

## 十一、衍生

衍生是调色盘的核心。衍生不是解释这个性格是什么意思，而是写这个颜色会如何变成行为。

每条衍生都要能回答至少一个问题：
- 她平时会怎么做。
- 她面对压力会怎么变。
- 她在某段关系里会露出什么不同。
- 这个性格会带来什么代价。
- 她什么时候会违背平时的样子。
- 她会如何处理利益、危险、名声、感情、责任。

衍生必须有可演绎的行为。写完一条衍生后，应当能直接拿去推动对话、选择或剧情。

## 十二、衍生的对冲

衍生需要有对冲，但不能每条都对冲。对冲是为了让人物从单一性格里长出复杂性。

对冲可以来自：
- 性格的代价。
- 身份的限制。
- 关系中的软肋。
- 长期习惯造成的盲点。
- 表面行为与真实选择的错位。
- 在特定压力下出现的反向反应。

对冲不能把人物写成前后矛盾。它要让人觉得这个人更完整，而不是忽然变成另一个人。

例如，一个很会守规矩的人，可以用规矩保护自己，也可以用规矩拒绝别人；一个总是精打细算的人，可以在某条底线上突然不算账；一个平时冷淡的人，可以不说安慰话，却把该准备的药和水提前放好。

## 十三、衍生的触发

人物不会时时刻刻表现出所有颜色。衍生要写触发条件。

触发条件可以是：
- 某个人出现。
- 某种目光。
- 某类称呼。
- 一份公文。
- 一笔账。
- 一件旧物。
- 一种场合。
- 一条门规。
- 一次危险。
- 一个弱者求助。

触发不是场景列表，而是人物反应的开关。写触发时，要写清触发后她会做什么。

## 十四、调色盘格式

推荐格式：

```text
——某人的调色盘——

人的性格就像调色盘。某人的底色来自……，主色调表现为……，点缀藏在……里。这些颜色让她在日常里……，在压力下……。

底色：……
主色调：……、……
点缀：……、……、……

底色名衍生一：标题
具体行为与适用场景。

底色名衍生二：标题
具体行为与适用场景。

主色调名衍生一：标题
具体行为与适用场景。

主色调名衍生二：标题
具体行为与适用场景。

点缀名衍生一：标题
具体行为与适用场景。
```

格式服务人物，不反过来束缚人物。主要人物可以写得更细，路人可以写得更短。

## 十五、人物生成与大夏秩序

大夏人物必须落在大夏秩序中。

门派人物要有师门规矩、山门资源、同门关系、门派名声。

官府人物要有官职权责、案牍压力、上级下属、可动用的人手。

军中人物要有军籍、军令、同袍、战功、军法。

商路人物要有货、账、债、护卫、路线、关津。

暗市人物要有牙人、担保、欠账、假身份、不能见光的交易。

世家人物要有门第、婚盟、田产、族规、长辈压力。

外邦人物要有来夏理由、使团或商路关系、语言礼法差异、母国利益。

普通百姓要有生计、邻里、户籍、恐惧、可提供的消息或帮助。

## 十六、人物可用性检查

人物生成后，检查以下问题：

- 她的身份是否能被追责。
- 她的生活来源是否明确。
- 她是否有当前正在处理的事。
- 她是否至少牵连两个人或两个势力。
- 她的外貌是否能被识别。
- 她的调色盘是否来自经历和身份。
- 她的衍生是否能变成行为。
- 她是否有一个会带来后续剧情的秘密、债、人情、麻烦或欲望。
- 她是否存在不能轻易越过的边界。

一个合格人物写完后，应当能自然回答：她为什么在这里，她想要什么，她怕什么，她会怎么做，她做了以后谁会受到影响。

## 十七、生成输出结构

生成完整人物时，按以下结构输出：

```yaml
角色档案:
  基本信息:
  外貌特征:
  背景设定:
  关系设定:
  当前处境:

调色盘:
  开头:
  底色:
  主色调:
  点缀:
  衍生:
```

输出内容要干净。基础信息不提前写性格，调色盘不写空泛词堆，衍生不做解释堆叠。人物必须能被放进剧情里使用。
