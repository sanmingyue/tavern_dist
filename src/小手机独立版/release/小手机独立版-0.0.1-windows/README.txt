小手机独立版 Windows 一键安装包

安装：
1. 确保电脑已安装 Node.js。
2. 双击 install.cmd。
3. 安装完成后桌面会出现“小手机独立版”快捷方式。

使用：
1. 先启动 SillyTavern。
2. 双击桌面“小手机独立版”。
3. 服务窗口或网页会显示配对码。
4. 在酒馆助手中导入桥接脚本：
   import 'https://testingcf.jsdelivr.net/gh/sanmingyue/tavern_dist@phone-standalone-v0.0.1/dist/小手机独立版/bridge-tavern/index.js'
5. 酒馆桥接和网页都输入同一个配对码。

手机访问：
手机和电脑连接同一个 Wi-Fi 后，打开服务显示的局域网地址，例如：
http://电脑IP:39231
