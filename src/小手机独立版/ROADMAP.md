# 实施路线

## 版本 A：跑通连接

目标：证明“独立小手机可以和酒馆实时互通”。

内容：

- 本地服务可启动。
- 独立网页可打开。
- 酒馆桥接脚本可连接服务。
- 酒馆新消息能推到独立网页。
- UI 显示连接状态和事件日志。

验收：

- 打开酒馆和独立网页。
- 酒馆收到一条 AI 消息。
- 独立网页无需刷新就出现这条事件。

## 版本 B：消息 App 迁移

目标：把旧版小手机最核心的“闪讯/消息”迁出来。

内容：

- 服务保存联系人和消息。
- UI 展示联系人列表和聊天窗口。
- 用户在小手机输入回复。
- 服务命令酒馆桥接脚本把回复写入酒馆输入框。

验收：

- 手机/电脑独立网页能看消息。
- 从小手机发送内容后，酒馆输入框出现格式化文本。

## 版本 C：本地数据库

目标：数据不再依赖浏览器缓存。

内容：

- SQLite 表结构。
- 聊天隔离。
- 联系人、消息、事件、设置入库。
- 备份导出。

验收：

- 重启浏览器、酒馆、小手机服务后数据仍在。
- 数据文件能在本地找到并备份。

## 版本 D：移动端兼容

目标：iPhone/安卓浏览器可用。

内容：

- 局域网访问配置。
- 配对码。
- iOS Safari 安全区和输入法适配。
- PWA manifest。

验收：

- iPhone Safari 打开电脑 IP 能进入小手机。
- 添加到主屏幕后可正常操作。
- WebSocket 断线后会自动重连。

## 版本 E：App 壳

目标：按需要封装。

内容：

- 桌面：Tauri 或 Electron。
- 安卓：Capacitor。
- iOS：只在确有需求时评估 TestFlight/签名成本。
