# 真实手机游玩说明

“手机玩，电脑给反应”的核心并不复杂：手机不是直接连酒馆，而是连接电脑上的小手机本地服务。

## 运行方式

```text
iPhone / 安卓手机
  -> 打开电脑的小手机网页
  -> 发送操作给本地服务
  -> 本地服务转发给酒馆桥接脚本
  -> 酒馆执行生成、写输入框、读聊天等动作
  -> 结果回到本地服务
  -> 手机界面实时更新
```

## 局域网版本

最先实现这个版本。

前提：

- 电脑和手机在同一个 Wi-Fi。
- 电脑运行 SillyTavern。
- 电脑运行小手机本地服务。
- 酒馆里启用小手机桥接脚本。

使用：

1. 电脑启动小手机服务。
2. 服务显示访问地址，例如 `http://192.168.1.23:39231`。
3. 手机浏览器打开这个地址。
4. 输入配对码或扫码。
5. 手机开始使用小手机界面。

## 为什么可行

手机浏览器可以访问同一 Wi-Fi 下电脑开放的网页服务。小手机界面本质上是一个网页，但数据和动作都由电脑上的本地服务处理。

酒馆仍然在电脑上运行，所以所有需要酒馆上下文的动作都由电脑完成：

- 读当前聊天。
- 监听 AI 新消息。
- 把小手机回复写入酒馆输入框。
- 调用酒馆生成。
- 注入小手机记忆。
- 写入或读取世界书。

手机只负责显示和操作，因此 iOS 不需要直接安装酒馆，也不需要直接读电脑文件。

## 首版限制

- 手机和电脑需要同一局域网。
- 电脑不能睡眠。
- 酒馆页面需要开着，桥接脚本需要连接。
- iOS Safari 后台运行能力有限，切出去太久可能断线，回来后需要自动重连。
- 首版不做系统级通知，只做网页内通知和红点。
