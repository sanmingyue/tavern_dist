# 澜景市整合世界书

这是由 `澜景市世界书编写稿_WB001-WB302.md` 与 `澜景市0604.json` 整合出的 tavern_sync 独立世界书源码项目。

## 澜景脚本运行约定

当前澜景市脚本不把这里作为 Tavern 世界书启用，也不依赖酒馆世界书扫描、递归或导入逻辑。

在脚本运行链路里，`世界书/00_规则层` 到 `世界书/04_设施详情` 只是澜景自己的文本资源库：脚本读取文件名和 txt 正文，前置检索层选择本轮要用的资源，随后脚本把正文内容组装进 `world_info_before`、`world_info_after` 和 D0 注入。

`05_角色人设` 暂不接入本轮组装，人设模块之后单独处理。

前置检索层只输出资源 ID，每行一个，最后一行 `END`。这份输出只是当轮正文生成的临时中间结果，不进入正文提示词，不写入变量，也不保存到聊天记录；重 ROLL 会重新检索、重新组装。

当前正文插入包按固定前缀分段：脚本权威状态、玩家人设与脚本状态、角色定义前插入包、在场角色组装、当前地点时间环境索引、角色定义后插入包、D0 系统插入包。
