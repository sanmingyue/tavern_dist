# 天材地宝归属与平衡索引

版本：v0.1
日期：2026-05-16
用途：记录北原魔土和大魔国天材地宝的产地、品级、采集门槛、流通限制和平衡问题，避免资源品级、价格、可得性和地图危险等级互相打架。

注意：本文是工作资料，不是世界书条目。本文只记录审查与索引，不替世界书正文补设定。

## 1. 审查规则

1. 高品级资源必须有高危险、低产量、势力封锁、禁地环境、传说未证实或采集后难保存等限制。
2. 同一资源在地图、物价、谋生指南、天材地宝文件中出现时，品级、价格、采集门槛必须互相支撑。
3. “可采集”不等于“普通角色可获得”。要区分外围低品、深层高品、传说级样本和势力禁物。
4. 圣级、天级资源不能成为常规经济品。若有价格，必须确认价格是否只是低纯度样本、黑市估价或旧设定错误。
5. 妖兽材料要同步检查妖兽境界和族群数量，避免材料稳定流通却没有对应生态压力。
