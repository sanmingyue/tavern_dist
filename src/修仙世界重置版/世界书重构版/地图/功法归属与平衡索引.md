# 功法归属与平衡索引

版本：v0.1
日期：2026-05-16
用途：记录重构版世界书中的功法品级、归属势力、流通范围、适配条件、风险代价和平衡问题，避免高阶传承泛滥、同名功法品级冲突、功法来源与角色战力不一致。

注意：本文是工作资料，不是世界书条目。不要把本文原样放进酒馆世界书。

## 1. 审查规则

1. 功法品级遵循世界观正序：凡 < 黄 < 玄 < 地 < 天 < 圣 < 仙。
2. 功法不禁阅只禁外传；境界未到则如观天书，不会因为看见高阶功法就立刻学会。
3. 广泛流通功法以黄级、少量玄级为主。地级以上功法若能被外人接触，必须是残篇、秘境未得、独修不传、代价巨大、难以领悟或会引来追杀。
4. 功法要和灵根、体质、境界、地域环境互相支撑。功法不匹配灵根会修炼缓慢甚至反噬。
5. 势力核心功法决定势力上限。天级、地级核心功法越多，越要检查该势力为什么没有横推周边。
6. 同名功法出现不同品级时，必须登记冲突并确认是版本差异、残篇/完整版差异，还是旧设定错误。
