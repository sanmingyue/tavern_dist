# 北原物价与经济索引

版本：v0.1
日期：2026-05-16
用途：记录北原魔土物价锚点、货币换算、区域差价和待复核价格，避免后续写资源、谋生、任务奖励时把同一种物品写出互相矛盾的价值。

注意：本文是工作资料，不是世界书条目。不要把本文原样放进酒馆世界书。

## 1. 货币锚点

| 项目 | 当前记录 | 结论 |
| --- | --- | --- |
| 灵石兑换 | 下品、中品、上品每级 1:1000 | 作为修士交易硬锚点保留 |
| 兽骨板 | 北原边境凡人通用货币，1 块约等于 1 斤低阶妖兽肉 | 仅边境、灰骨城、霜风镇等低阶凡人市场通行 |
| 边境兑换 | 1 下品灵石约 100-200 兽骨板 | 可用；帝都购买力明显低于边境 |
| 灵石碎片 | 帝都散摊区使用，但未定义换算 | 需补充标准换算，避免低端消费混乱 |

## 2. 区域价格锚点

| 区域 | 物价特征 | 已确认锚点 | 待注意 |
| --- | --- | --- | --- |
| 北原边境 | 兽骨板为主，低阶丹药稀缺 | 疗伤丹黄级下品 5-10 下品灵石；粗盐断供会涨到 10+ 兽骨板 | 与帝都价格差异合理，别把边境写成稳定修士市场 |
| 天魔帝都 | 灵石市场完整，低端有灵石碎片 | 黄级功法 10-50 下品灵石；玄级功法 1-5 中品灵石；金丹级法器 1-10 中品灵石 | 内城、外城、散摊区价格应分层 |
| 焚魔焦土 | 火属性资源和矿业交易 | 火灵矿原矿 30-80 下品灵石/块；火山集市过路费 5-10 下品灵石 | 炎铁武器比帝都贵 20% 但质量更好 |
| 泣血山脉矿区 | 现场价低于帝都 | 血髓矿现场价约帝都的 60%-70% | 必须区分浅层普通矿与深层高品矿 |
| 永夜冰原 | 外族消费高，冰魔族内部不完全用灵石 | 永夜城入城费 20 下品灵石；城内外族旅舍 10-20 下品灵石/夜；外城客区冰砖客栈 5 下品灵石/夜；冰魂晶 100-300 下品灵石/枚；万年玄冰 50-150 下品灵石/块 | 已确认城内、客区分层；仍需确认冰魔族内部交换体系 |
| 黑冰港 | 走私溢价 | 走私材料通常比正常渠道贵 30%-50%，运输抽 10%-20% | 价格波动大，需结合寂灭海和影魔族秩序 |
| 万法楼 | 等价交换 | 客舍免费但必须是客人；知识交易不只收灵石 | 不要给万法楼高阶知识直接标固定价，需按司空玄定价 |

## 3. 税费、服务与特殊交易锚点

| 类型 | 当前记录 | 待注意 |
| --- | --- | --- |
| 灰骨城庇护税 | 每月每人 10 兽骨板，约 0.05-0.1 下品灵石 | 与边境兑换一致，是凡人长期压力而非修士级开销 |
| 帝都入城费 | 1 下品灵石 | 和帝都外城日收入、食宿成本一起看 |
| 帝都内城令牌 | 非卖品，需内城居民担保 | 不应被普通灵石直接购买 |
| 火山集市过路费 | 5-10 下品灵石/人 | 与焚魔焦土矿业收益匹配 |
| 帝都散摊区摊位介绍费 | 鬼手帮收 5 下品灵石 | 是入场介绍费，不等同官方税 |
| 万禁教解印 | 100+ 下品灵石起，视封印等级 | 高阶封印不得固定低价，需按难度走 |
| 万法楼知识交易 | 灵石、法宝、秘密、功法、经历皆可等价交换 | 高阶知识必须由司空玄定价，不写固定价 |
| 黑冰港走私运输 | 按货值抽 10%-20% | 与走私材料 30%-50% 溢价并存 |
| 帝都情报 | 简单消息 10 下品灵石起，复杂情报 50-200 灵石 | 与耳目体系绑定，消息级别需分层 |
| 灰骨城情报 | 孙瞎子城内消息 3 兽骨板，老鬼头生存指南 5 兽骨板 | 低端本地消息，不要和帝都情报价混用 |
| 帝都奴隶 | 凡人成年男 5 下品灵石，凡人成年女 3-8 下品灵石，孩童 1-3 下品灵石 | 旧设定黑暗经济锚点，后续处理奴隶市场要注意尺度和势力反应 |
| 修士奴隶 | 炼气 50-200 下品灵石，筑基 500-2000 下品灵石，有灵根底价十倍，特殊体质拍卖 | 高资质/特殊体质不设固定上限，必须走拍卖和势力争夺 |

## 4. 谋生收入锚点

| 场景 | 身份 | 当前收入记录 | 待注意 |
| --- | --- | --- | --- |
| 霜风镇 | 凡人猎人 | 3-8 兽骨板/日 | 老猎场相对安全，继续北上风险骤增 |
| 霜风镇 | 凡人采集 | 1-3 兽骨板/日 | 低风险低收入，适合老人和妇女 |
| 霜风镇 | 向导 | 10-20 兽骨板/趟 | 需熟悉地形和妖兽分布 |
| 灰骨城 | 凡人猎人 | 5-15 兽骨板/日 | 筑基级妖兽出没，死亡率高 |
| 灰骨城 | 搬运工 | 2-3 兽骨板/日 | 月初庇护税 10 兽骨板是主要压力 |
| 天魔帝都外城 | 凡人杂役/跑腿/摆摊 | 1-10 灵石/日波动 | 与边境兽骨板收入差距极大，需用帝都物价、魔气折寿和机会成本解释 |
| 永夜城外城客区 | 外族凡人杂活 | 1-2 灵石/日或管饭 | 活少但能活下去，依赖客区暖域与冻梨、姜婆等节点 |
| 焚魔焦土灰烬营地 | 凡人杂活/扛工具 | 1-3 灵石/日 | 热、累、危险，且矿区奴隶劳动会压低自由凡人工价 |
| 黑冰港旧船坞 | 凡人端酒、洗衣、看场 | 管饭、小费或 1-2 灵石/日 | 便宜但乱，容易挨打，依赖断桅、锈钉、六指等底层秩序 |
| 泣血山脉 | 凡人矿工 | 3-5 兽骨板/日 | 血气侵蚀会导致嗜血发狂，不能只看收入 |
| 通用低阶修士 | 炼气猎妖 | 5-20 灵石/日 | 收益看区域和妖兽阶位，风险随深入上升 |
| 通用低阶修士 | 筑基猎妖 | 20-100 灵石/日 | 不应在安全区长期稳定满收益 |
| 通用低阶修士 | 商队护卫 | 霜风镇到灰骨城 5-10 灵石/趟；帝都线路 20-50 灵石/趟 | 需按路线危险度和雇佣方付款能力区分 |
| 宗门弟子 | 幽血门外门 | 宗门包食宿但无薪水 | 一切靠训练、角斗、猎杀和任务争取 |
| 等候区 | 万禁教客舍 / 万法楼候客谷 / 幽血门战堡外围 | 多数不是谋生地点，只是等待和接引 | 不要把等候区写成稳定打工点 |
