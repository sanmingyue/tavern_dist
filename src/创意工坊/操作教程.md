本教程分为**我帮你写的代码部分**和**你需要手动操作的部分**。代码我来写，你只需要按教程完成手动操作。

## 📋 总览

整个流程是这样的：

```
第1步：我写好后端代码 → 你在桌面得到一个 workshop-server 文件夹
第2步：你去 Discord 创建一个应用 → 得到 Client ID 和 Secret

第4步：你在 Zeabur 部署这个仓库

```

## 第 2 步：创建 Discord 应用（你来做）

### 2.1 打开 Discord 开发者后台

1. 用浏览器打开：https://discord.com/developers/applications
2. 用你的 Discord 账号登录

### 2.2 创建新应用

1. 点击右上角的 **"New Application"** 按钮
2. 输入名称：`三明月创意工坊`（或者你喜欢的名字）
3. 勾选同意条款，点击 **"Create"**

### 2.3 记录 Client ID

1. 创建完后会进入应用的 **"General Information"** 页面
2. 找到 **"APPLICATION ID"**（也叫 Client ID）
3. 点击旁边的 **"Copy"** 按钮，**把它记下来**

> 📝 记下来：`APPLICATION ID = 1501164439054061590_______________`

### 2.4 获取 Client Secret

1. 左侧菜单点击 **"OAuth2"**
2. 在 **"Client Secret"** 区域点击 **"Reset Secret"**
3. 弹窗确认后，会显示 Secret，点击 **"Copy"**
4. **立刻把它记下来，这个只会显示一次！**

> 📝 记下来：`CLIENT SECRET = JGugF2pIJ9eNcmZ71bpDqTqxwrtjI7Y2_______________`

### 2.5 设置重定向 URL（先跳过，等第 4 步拿到域名后再回来填）

这一步需要 Zeabur 给的域名，所以先跳过。等你部署完成拿到域名后再回来。

### 2.6 设置 Bot 权限（可选但推荐）

1. 左侧菜单点击 **"Bot"**
2. 点击 **"Add Bot"**
3. 这个 Bot 不需要添加到服务器，但有了它可以更好地验证用户身份

## 第 4 步：在 Zeabur 部署（你来做）

### 4.1 添加新服务

1. 打开 Zeabur 控制台：https://dash.zeabur.com
2. 进入朋友拉你的那个项目
3. 点击 **"Add Service"**（添加服务）
4. 选择 **"Deploy from GitHub"**（从 GitHub 部署）
5. 找到并选择 `workshop-server` 仓库
6. Zeabur 会自动检测这是一个 Node.js 项目并开始构建

### 4.2 添加持久化磁盘

SQLite 数据库文件需要持久化存储，否则重新部署后数据会丢失。

1. 点击你刚创建的服务
2. 找到 **"Storage"** 或 **"Disk"**（存储/磁盘）选项
3. 点击 **"Add Persistent Storage"**（添加持久化存储）
4. Mount Path（挂载路径）填：`/data`
5. 大小选 1GB 就够了

### 4.3 设置环境变量

1. 在服务设置中找到 **"Variables"**（环境变量）
2. 添加以下环境变量：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `DISCORD_CLIENT_ID` | 你在第 2 步记下的 APPLICATION ID | Discord 应用 ID |
| `DISCORD_CLIENT_SECRET` | 你在第 2 步记下的 CLIENT SECRET | Discord 应用密钥 |
| `DISCORD_GUILD_IDS` | `1380075940285124724,1134557553011998840` | 允许的 Discord 服务器 ID |
| `ADMIN_DISCORD_IDS` | 你自己的 Discord 用户 ID | 管理员的 Discord ID |
| `SESSION_SECRET` | 随便打一串字符如 `smy-workshop-2026-secret-key` | 会话密钥 |
| `BASE_URL` | （等域名出来后填） | 后端服务的完整 URL |

> 💡 **如何获取你自己的 Discord 用户 ID：**
> 1. 打开 Discord 客户端
> 2. 设置 → 高级 → 打开"开发者模式"
> 3. 点击自己的头像 → 右键 → "复制用户 ID"

### 4.4 绑定域名

1. 在 Zeabur 服务设置中找到 **"Networking"** 或 **"Domain"**
2. Zeabur 会提供一个免费的子域名，如 `workshop-server-xxxxx.zeabur.app`
3. 记下这个域名

> 📝 记下来：`域名 = _______________`

### 4.5 回填域名信息

拿到域名后，需要做两件事：

**A. 更新 Zeabur 环境变量**

把 `BASE_URL` 设置为：`https://你的域名`（如 `https://workshop-server-xxxxx.zeabur.app`）

**B. 回到 Discord 开发者后台设置重定向 URL**

1. 打开 https://discord.com/developers/applications
2. 点击你创建的应用
3. 左侧点击 **"OAuth2"**
4. 在 **"Redirects"** 区域点击 **"Add Redirect"**
5. 填入：`https://你的域名/auth/discord/callback`
6. 点击 **"Save Changes"**

### 4.6 验证部署

部署完成后，在浏览器打开：`https://你的域名/health`

如果看到 `{"status":"ok"}` 就说明部署成功了！

打开 `https://你的域名/admin` 可以进入管理后台（需要先 Discord 登录）。
