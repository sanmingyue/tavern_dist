# 创意工坊修复计划

更新时间：2026-05-07

## 已完成

### 上传/下载/注入文件逻辑改造（2026-05-07）

已实施的改动：

#### 类型系统
- 新增 `character`（角色卡）类型
- 新增 `AddonSubtype` 类型（card_addon 子类型：worldbook / regex / persona）
- `addon_subtype` 编码到 `file_type` 字段（如 `json:worldbook`、`json:regex`、`json:persona`）

#### 上传流程
- `regex`/`worldbook`/`character`：改为文件上传（不再用 textarea 粘贴内容）
- `character`：支持 JSON 和 PNG 文件，必须填写角色卡链接
- `persona`：保持现有表单（正文 + 世界书条目属性），不变
- `card_addon`：新增子类型选择（worldbook/regex/persona），子类型为 persona 时复用世界书属性表单，其他子类型走文件上传
- `collection`：不变

#### 下载/注入流程
- `regex`：下载原 JSON 文件；导入调用 `importRawTavernRegex`
- `worldbook`：下载原世界书 JSON 文件；导入调用 `importRawWorldbook`（文件名自动附带作者名）
- `character`：下载原 JSON/PNG 文件；导入调用 `importRawCharacter`
- `persona`：注入到角色卡绑定世界书（`createWorldbookEntries`）；**下载为完整可导入的酒馆世界书文件**（`{"entries":{...}}` 格式）
- `card_addon`：按 addon_subtype 路由到对应的下载/注入逻辑

#### 后端变更
- `VALID_TYPES` 新增 `character`
- multer fileFilter 支持 `.json` 文件（仅 card_file 字段）
- POST 路由：character 校验 card_link + card_file；regex/worldbook 读取上传文件内容存入 content；card_addon 接收 addon_subtype
- database.ts 无需改动（复用 content + file_type + `__card_file__:<filename>` 方案）

#### 向后兼容
- 现有 regex/worldbook 作品内容是纯文本 JSON，下载时仍原样返回
- 现有 persona 旧纯文本内容注入时仍兼容（`parseWorldbookEntriesFromContent` 的 fallback 逻辑不变）

### 历史下载去重与下载次数计数（2026-05-07）

已实施的改动：

#### database.ts
- 新增 `hasUserDownloaded(userId, workId)` 函数：检查用户是否已下载过该作品
- `recordDownload()` 改为 upsert 语义：同一用户+同一作品只保留一条 downloads 记录
  - 首次下载：INSERT 新记录
  - 重复下载：UPDATE 已有记录的时间戳、版本、IP、指纹等字段
  - 指纹和 download_fingerprints 表仍每次更新（保留审计追溯能力）

#### routes/works.ts
- 下载接口 `GET /api/works/:id/download` 改为先用 `hasUserDownloaded()` 判断
- `incrementDownloadCount()` 只在用户首次下载该作品时调用
- 重复下载/注入不再增加 `download_count`
- 审计日志（audit_logs）仍每次记录，不受影响
