---
变量更新规则:
  当前日期:
    format: YYYY年MM月DD日 星期X
    check:
      - 每次场景转换或时间跳跃后更新
      - 保持日期与星期的对应关系正确
  当前时段:
    type: enum('早晨', '上午', '午休', '下午', '傍晚', '晚自习', '深夜')
    check:
      - 根据剧情中的时间推进更新
      - 每次场景转换或时间跳跃后更新
  ${角色名}.好感度:
    type: number
    range: -100~100
    check:
      - 根据角色对<user>行为的感知和反应调整 ±(0.1~1)
      - 仅在该角色当前察觉到<user>的行为时才更新
      - 正面互动（帮助、理解、陪伴）增加，负面互动（忽视、伤害、背叛）减少
      - 单次变化通常不超过 +1，除非发生重大事件。但是可减少部分无上限.
  ${角色名}.关系状态:
    check:
      - 普通角色（洛月/宋雨欣/司菲/慕言/云初夏/洛蓉/苏琪）：初识 → 熟悉 → 暧昧 → 恋人/决裂
      - 教师角色（苏晴/沈曼莎/厉莎）：师生 → 暧昧 → 恋人/封心
      - 亲缘角色（程妞妞）：亲密无间 → 暧昧 → 恋人/疏远
      - 关系状态变更必须由特定剧情事件触发，不能仅因好感度达标就自动变更
      - 好感度达到100只代表告白长线可以开始，不能因此直接进入恋人、决裂、封心或疏远
      - 告白长线中只能按剧情更新关键事件，正式告白尚未发生前不得把关系状态改为恋人、决裂、封心或疏远
      - 只有在角色已经完成专属告白长线并正式向<user>告白后，才允许根据<user>的明确回应更新关系状态
      - <user>明确接受、愿意交往、愿意共同面对现实阻碍时，才可进入恋人
      - <user>明确拒绝、否定这份感情、表示不能接受继续发展时，普通角色进入决裂，教师角色进入封心，程妞妞进入疏远
      - <user>沉默、转移话题、含糊、逃避、暂时需要思考时，不视为接受或拒绝，关系状态保持不变，由角色继续等待、退让或确认
      - 决裂/封心/疏远状态不可逆转
  ${角色名}.关键事件:
    type: |-
      {
        [事件名: string]: boolean;
      }
    check:
      - 记录角色线中的重要剧情节点
      - 事件发生时设为true，用于标记剧情进度
      - 告白事件应拆分记录，例如：告白事件_引导开始、告白事件_第一段完成、告白事件_第二段完成、告白事件_第三段完成、正式告白已发生
      - 只有实际完成对应剧情段落时才更新，不要提前补全整条告白事件
      - 如：告白事件、身份暴露、关键抉择、家人认可、离婚决定等
  全局标记.身份暴露_云初夏:
    type: boolean
    check:
      - 当<user>通过任何方式发现云初夏的真实性别时设为true
      - 一旦设为true不可逆转
  全局标记.告白发生:
    type: |-
      {
        [角色名: string]: boolean;
      }
    check:
      - 只有某角色已经完成专属告白长线、正式告白已经说出口，且<user>已经明确接受或明确拒绝后，才记录为true
      - 告白引导开始、告白事件推进中、正式告白后等待回应时，都不能记录为true
      - 无论最终接受或拒绝，只要回应已经明确并进入对应终局，就记录为true
