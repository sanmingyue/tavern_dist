# 天命华夏 — 设计规划文档

> 本土化中国古神话世界观的天命征伐框架，以"愿望"为驱动、"天性"为核心力量来源。

---

## 一、世界观核心概念

### 1.1 神话即真实

在这个世界中，华夏所有的神话传说都是**真实发生过的历史**。

盘古开天、女娲造人、后羿射日、精卫填海、大禹治水、封神大战……这一切都真实存在。只是随着岁月流逝，普通人已无法感知神力，将亲眼见证的奇迹口口相传为"故事"，将山海经视为"古人的想象"。

**众神隐退**：上古大战之后，诸神相互制约，立下契约——**禁止下凡干涉人间**。从此，神话时代结束，人间进入不知神灵的"凡世"。

### 1.2 天命玺

| 概念 | 说明 |
|------|------|
| **天命玺** | 上古神器，传说中记录着天道意志的玺印。得者可向天道许下一个愿望，改写既定命运。 |
| **天命征伐** | 围绕天命玺展开的神使召唤与角逐。 |
| **召命者** | 被天命玺选中的普通人。 |
| **神使** | 被召唤降临的古神投影/分身。 |
| **天谕符** | 刻于召命者身上的三道符文，可强制指挥神使，或在关键时刻引爆以增幅。 |

### 1.3 天命征伐的规则

每隔数十年，天命玺的封印自行松动，降临于华夏某座城市。

**选中机制**：天命玺感应城市中拥有**最强烈执念与愿望**的人，共选出**七位召命者**，在他们身上刻下天谕符。被选中的人会听到一个声音，引导他们：

> **"感受……召唤……夺取。"**

召命者就此被卷入天命征伐。

**胜利条件**：消灭其余所有神使。最后存活的神使所属的召命者获得天命玺，许下愿望。

**感知扭曲**：天命玺拥有扭曲普通人感知的能力。天命征伐期间的一切战斗破坏、人员伤亡，在征伐结束后都会被**完全修复**。普通人不会记得任何异常，世界恢复如初——仿佛什么都没有发生过。

### 1.4 召命者

**召命者全部是普通人。** 没有修士、术士、特殊血脉——纯粹是因为内心的执念足够强烈而被选中。

可能是为了救治绝症的亲人、为了找回失踪的孩子、为了弥补一个无法挽回的遗憾……每一个召命者的愿望都是真实且沉重的。

**所有人都为了真实的愿望而来。没有人是为了战斗本身而战斗。**

### 1.5 神使

天命征伐是众神禁止下凡后，极为罕见的**"合法降临"机会**。

- 神使是古神的**投影/分身**，而非本体。本体无法下凡。被消灭不影响本体存在。
- 神使**没有自己的愿望**，他们参与天命征伐纯粹是因为——这是难得的下凡机会。
- 不同的神有不同的下凡理由：有的想重温人间、有的想再战一场、有的只是好奇。
- 神使被召命者的信念共鸣所召唤，一般只要感应到召唤，都会愿意降临。

### 1.6 故事发生地

**虚构城市**（暂未命名）。一座有山有水、历史悠久的古城，地下沉睡着远古灵脉。天命玺选择在此显现，并非偶然。

## 二、召唤系统 ── 剪影抽取

### 2.1 剪影召唤

召命者被选中后，进入召唤仪式。眼前浮现数个**神使剪影**——只能看到模糊的轮廓，无法确定身份。

**剪影是故意混淆的。** 同一个剪影可能对应完全不同的神使：

| 剪影描述 | 可能召唤到 |
|---------|-----------|
| 持棍猴影 | 孙悟空 / 六耳猕猴 |
| 三头六臂少年 | 哪吒 / 殷郊 |
| 执弓仰射者 | 后羿 / 帝羿 |
| 持戟天将 | 杨戬 / 韦驮 |
| 无头巨人 | 刑天 / 夸父 |
| 蛇尾女神 | 女娲 / 伏羲 |
| ……更多待扩展 | |

### 2.2 召唤流程

1. 多个剪影同时出现，玩家**选择一个剪影**
2. 选择后，投影立刻降临，**身份揭晓**
3. 你以为选的是孙悟空，结果可能是六耳猕猴——天性完全不同，打法也要跟着变

这意味着：**玩家选的是剪影，不是角色。** 同一个剪影的不同结果，带来截然不同的游戏体验。

## 三、神使系统 ── 天性决定一切

### 3.1 核心设计原则

**天命征伐中没有固定的强弱排序。**

- 神使的投影初始只能发挥**本体的一部分实力**
- **契合度越高，投影能发挥的本体实力越大**——就这么简单
- 战斗经验是神使本身自带的——孙悟空本来就会打，后羿射箭本来就准，不需要"升级"
- 符合天性的战斗场景下，神使战力额外增强；违背天性则消极甚至拒绝行动

### 3.2 契合度

契合度的提升方式是**完全角色化的**，没有固定公式，必须符合每位神使的性格特点：

- 对哪吒骂他爹 → 契合度涨（他就是恨李靖）
- 给孙悟空一颗桃 → 契合度涨（蟠桃的记忆）
- 对六耳猕猴说"你像孙悟空" → 契合度暴降（她最恨被当成替身）
- 在后羿面前提起嫦娥 → 效果未知，取决于怎么提
- 让姜子牙有充分时间布局 → 契合度涨（他就是需要时间）

**AI 必须深入理解每位神使的性格、历史、雷区和喜好，才能正确判定契合度变化。**

### 3.3 天性路

每位神使都有其专属的**天性路**——只有沿着这条路走，才能发挥真正的力量。召命者的智慧在于理解神使的天性，为其创造最适合发挥的战场。

### 3.4 神使名录（奖池）

> 所有神使均来自中国古神话体系：上古创世、山海经、封神演义、西游记、道教等。
> 以下为全部候选神使的一句话天性概括。详细设定后续逐个展开。

### 3.5 天性碰撞

神使之间的战斗不只是数值比拼，更是**天性路的对撞**：

| 对阵 | 天性互动 |
|------|---------|
| 孙悟空 vs 玉皇大帝 | 无法无天 vs 天道秩序——孙悟空在这场战斗中必定全力燃起 |
| 精卫 vs 刑天 | 两个"永不放弃"的存在对撞——这场战斗可能永远无法结束 |
| 共工 vs 女娲 | 毁灭 vs 修补——共工越破坏女娲越强，但女娲越修补共工越愤怒 |
| 杨戬 vs 姜子牙 | 洞察真相 vs 深藏计谋——杨戬能看穿一切伪装，但姜子牙的计划本身就是"真相" |
| 哪吒 vs 太乙真人 | 反抗者 vs 引导者——师徒关系的延续 |
| 蚩尤 vs 后羿 | 制造混乱 vs 孤独守护——蚩尤越制造战争后羿越有保护的对象，两者互相激活 |

## 四、心契系统

### 4.1 道心相印

召命者与神使之间的精神共鸣程度，称为**道心相印值**（契合度，1%～100%）。

**契合度 = 投影能发挥本体多少实力。** 就这么简单。

契合度越高 → 投影越接近本体的真实力量。

### 4.2 契合度的提升

**没有固定公式。** 完全取决于召命者与神使之间的互动是否符合神使的性格。AI 根据每位神使的天性、历史、雷区和喜好来判定每次互动对契合度的影响。

### 4.3 心印等级

| 契合度 | 等级 | 效果 |
|--------|------|------|
| 1%～20% | **陌路** | 投影仅发挥极少本体实力，神使态度冷淡 |
| 21%～40% | **识途** | 投影发挥部分实力，神使开始分享记忆和建议 |
| 41%～60% | **知己** | 投影发挥正常实力，神使自主发挥 |
| 61%～80% | **共鸣** | 投影接近本体实力，双方可进行战术配合 |
| 81%～99% | **道侣** | 投影高度接近本体，神使愿意为召命者牺牲 |
| 100% | **天人合一** | 投影等同本体全力 |

## 五、战斗系统

### 5.1 伪回合战斗框架

**表层**：AI 以实时流畅的叙事方式描写战斗过程，有来有往，气势磅礴
**底层**：实际上是回合制，每轮由以下步骤构成：

```
召命者选择行动方针（策略/战术/具体行动）
    ↓
AI 判定：此行动是否符合神使天性？
    ↓
AI 处理双方神使交锋，天性状态影响实际战力
    ↓
AI 给出战斗结果 + 当前状态变化 + 契合度反馈
    ↓
循环下一轮
```

### 5.2 战斗资源

**神使资源**

| 资源 | 名称 | 说明 |
|------|------|------|
| ❤️ | **神躯值** | 归零则神使投影被消灭 |
| 💙 | **灵力值** | 消耗灵力使用神通 |
| 🔥 | **天性燃起** | 当前天性契合程度（低燃/正燃/全燃），影响实际战力 |

**召命者资源**
- 💛 **魂力**：召命者自身的生命/精神力，耗尽则失去召命资格
- 🔴 **天谕符**：仅剩三道，使用后不可再生

### 5.3 战斗判定要素

AI 判定战斗时需考虑：
- 双方神使的契合度（投影能发挥本体多少实力）
- 当前天性契合状态（天性燃起程度）
- 地利因素（战场环境与神使天性的契合度）
- 召命者主动参与度与决策质量

### 5.4 天谕符的代价

使用天谕符强制令神使**违背天性**行动时：
- 消耗**两道**天谕符而非一道
- 神使虽然执行，但契合度永久下降
- 某些神使（如哪吒）在被强制后，可能在下一回合反噬召命者

## 六、剧情架构

### 6.1 核心体验

**战斗爽 + 升级（契合度） + 智斗**

不搞复杂暗线。核心就是：
1. 选到一个神使
2. 理解他/她的天性
3. 在一场场战斗中提升契合度
4. 用智慧和对神使的理解，击败其他召命者
5. 夺取天命玺，实现愿望

### 6.2 基本流程

1. **开局**：玩家被天命玺选中，听到引导声音
2. **召唤**：剪影出现，玩家选择，投影降临
3. **探索**：了解天命征伐规则，与神使互动，提升契合度
4. **角逐**：遭遇其他召命者，战斗、结盟、智斗
5. **决战**：最终对决
6. **愿望**：胜者许愿

每位NPC召命者都有真实的愿望。具体设定后续讨论。
