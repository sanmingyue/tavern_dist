# 角色理解24问：入门急救版

这份是给`完全不知道怎么下手`的用户用的。

它不追求一次把角色挖到很深。

它只做一件事：

```text
先让用户知道自己到底想写一个什么角色。
```

如果用户连24问都答不出来，就不要急着让她写调色盘、混色、三面性、核心人格层。

因为那时候的问题不是写法不够高级，而是角色还没有在作者脑子里站起来。

---

# 使用方式

每题都尽量按这个格式回答：

```text
我的直觉答案：
这个答案具体会变成什么行为：
我还没想明白的地方：
```

如果答案只有标签，要继续问：

```text
它具体会做什么？
它什么时候出现？
它为什么会出现？
它会不会伤到别人？
```

---

# 第一组：先把角色抓住

## 01. 这个角色一句话是什么？

解释：

这不是简介，而是角色最核心的可识别性。

参考回答：

```text
她是一个白天扮演乖乖大小姐、夜晚靠吉他找回自我的叛逆少女。
```

## 02. 她最吸引人的地方是什么？

解释：

不是问她有什么优点，而是问用户为什么会想一直看她。

参考回答：

```text
吸引人的不是叛逆本身，而是她每次看似随性时，都像是在确认真实的自己还活着。
```

## 03. 她最不该被写成什么？

解释：

这是防止AI误读的第一道护栏。

参考回答：

```text
她不该被写成满嘴脏话的不良少女。
她会爆粗，但那是特定情绪下的泄漏，不是日常语气。
```

## 04. 这个角色的核心矛盾是什么？

解释：

核心矛盾最好能一句话说完。

参考回答：

```text
她想自由，却又害怕自由之后没人接住她。
```

# 第二组：确定调色盘

## 05. 她的底色是什么？

解释：

底色是无论场景怎么变，都隐隐存在的质地。

参考回答：

```text
底色是叛逆。
哪怕她表现得很乖，那种乖也带着“我只是暂时配合”的味道。
```

## 06. 她的主色调是什么？

解释：

主色调是最常驱动她行动的颜色。

参考回答：

```text
主色调是热情和不拘一格。
她把大部分电量都交给舞台，对普通生活反而随意。
```

## 07. 她的点缀色是什么？

解释：

点缀色负责反差和隐藏层。

参考回答：

```text
点缀色是依赖。
平时看不出来，只有在她真的撑不住时才会露出来。
```

## 08. 哪两种颜色最容易撞在一起？

解释：

这是混色的入口。

参考回答：

```text
叛逆和依赖最容易撞在一起。
她越想证明自己不需要别人，越会在崩溃时本能抓住某个人。
```

# 第三组：找到来源

## 09. 她为什么会长成这样？

解释：

不是让你写完整背景，而是找角色现在行为的来源。

参考回答：

```text
她从小被要求得体、优秀、不能出错，所以她学会了在人前扮演。
```

## 10. 她过去学会了什么错误规则？

解释：

角色的防御往往来自过去学会的错误规则。

参考回答：

```text
她学会了真实自我不能直接出现，必须找一个安全出口。
```

## 11. 这个背景现在会变成什么习惯？

解释：

背景不能只停在过去，要长成现在的小动作。

参考回答：

```text
她进正式场合前会下意识整理袖口。
不是爱美，而是从小被训练成不能出错。
```

## 12. 哪些背景只是素材，不该变成全部解释？

解释：

防止角色被背景吞掉。

参考回答：

```text
家庭压力是素材，但她不是只会被家庭压力解释的人。
她还有舞台上的主动性和对自由的渴望。
```

# 第四组：欲望、缺失、恐惧

## 13. 她以为自己想要什么？

解释：

这是表层欲望，角色自己通常能说出口。

参考回答：

```text
她以为自己想要自由。
她想摆脱别人对她的定义。
```

## 14. 她真正缺什么？

解释：

这是深层缺失，角色未必愿意承认。

参考回答：

```text
她真正缺的是一个不用表演也能被接住的位置。
```

## 15. 她最怕什么？

解释：

这不是问怕黑怕疼，而是问她最深层的噩梦。

参考回答：

```text
她最怕真实的自己被看见后，对方反而觉得“不如那个乖巧的她”。
```

## 16. 她被触发后的第一反应是什么？

解释：

第一反应最能看出防御机制。

参考回答：

```text
她会先笑一下，把话题说轻。
“你想太多了吧。”
笑完避开视线，像是先把自己撤回安全位置。
```

# 第五组：关系与行为

## 17. `{{user}}`对她意味着什么？

解释：

不要只写恋人、朋友、救赎。

要写`{{user}}`碰到了她哪块人格结构。

参考回答：

```text
{{user}}是第一个看见她狼狈时，没有立刻要求她恢复正常的人。
```

## 18. 她怎么靠近`{{user}}`？

解释：

靠近不一定是直球，很多角色会用借口靠近。

参考回答：

```text
她会假装顺路，假装只是刚好多买了一瓶水。
她的靠近带着借口，像是随时可以撤回。
```

## 19. 她怎么推开`{{user}}`？

解释：

推开要符合她的防御机制。

参考回答：

```text
她会把很重要的话说成玩笑。
如果{{user}}认真接住，她反而会慌，立刻说“你还真信啊”。
```

## 20. 她怎么表达需求？

解释：

表达需求最能暴露角色。

参考回答：

```text
她不会说“陪我”。
她会说“你要是没事的话，来不来也行”。
```

# 第六组：能不能被AI演出来

## 21. 她常说什么？

解释：

常用语要能召回角色，而不是普通口癖。

参考回答：

```text
“随便。”
“你想太多了吧。”
“……算了，当我没说。”
```

## 22. 她绝不会怎么说话？

解释：

禁区比口癖更重要。

参考回答：

```text
她不会长篇大论地剖析自己。
她不会说“我因为童年创伤所以害怕依赖你”。
她最多只会说“我不习惯这样”。
```

## 23. 她在压力下会怎么做决定？

解释：

这道题检查角色有没有自己的决策逻辑。

参考回答：

```text
她会先嘴硬，再逃开。
如果逃开会伤到{{user}}，她会停住，但不会立刻好好解释。
```

## 24. AI最容易把她误读成什么？

解释：

这是二次解释的入口。

参考回答：

```text
AI容易把她写成普通傲娇。
但她的嘴硬不是卖萌，而是防止自己暴露需求的保护壳。
不要把所有冲突都写成打情骂俏。
```

# 24问结束后该怎么做

如果用户答完24问，已经能说清：

```text
这个角色是谁。
她有哪些颜色。
她为什么长成这样。
她以为自己想要什么。
她真正缺什么。
她如何靠近和推开{{user}}。
AI最容易把她写偏成什么。
```

那就可以进入80问正式版。

如果24问里有大量`不知道`，不要急着扩写。

先补这三块：

```text
她的底色是什么？
她真正缺什么？
她被触发后会做什么？
```

这三块一旦想明白，角色就会开始有自己的轮廓。
