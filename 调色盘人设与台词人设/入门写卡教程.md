
# 入门写卡教程：让角色活过来的最短路径

by 三明月

---

写在前面：这篇教程面向完全不知道怎么下手的人。

如果你已经看过调色盘教程、三面性教程、混色教程，这篇对你来说太基础了，不用看。

如果你还没看过那些，或者看了但觉得太复杂不知道怎么开始，这篇就是给你的。

这套写法不需要你学会拆底色主色调点缀，不需要你理解什么是三面性，不需要你搞明白混色画面怎么构建。

你只需要做几件事：写一份基础信息，写几段小传，做一次采访，写一张情绪阈值表，想一个意象。

但在那之前，你需要先明白一件事：你写的这些东西喂给AI以后，AI到底在干什么。

# 第一章：AI到底在干什么

## 输入法联想

你手机上打字的时候，输入法会弹联想词。

你打"你好"，输入法弹出来"在吗""吃了吗""最近怎么样"。

输入法怎么知道弹这几个？因为它统计了几百万条聊天记录，发现"你好"后面跟"在吗"的次数最多，所以"在吗"排第一。

AI干的事和这个一模一样。

你给AI一句话，AI预测下一个词应该是什么。预测完第一个词，把这个词加上去，再预测下一个。一个词一个词地接，接成一整段话。

你手机输入法只看前面一两个词来联想。AI看的是你给它的所有内容。角色卡、聊天预设、你打的每一句话、之前的聊天记录，全部都在影响它接下来选哪个词。

所以AIRP在做的事，说白了就是：你把所有的内容喂给AI，AI拿这些内容当上下文，去决定"下一个词选什么"。

## 上下文决定联想词

你给的上下文越具体、越独特，AI选出来的词就越不一样。

你给的上下文越空、越泛，AI就会选那些最常见的、最安全的词。

举个例子。你写"性格：温柔"，AI给你出来的全是一个模子刻出来的温柔。"微笑""轻声说""柔和的目光"，翻来覆去就那几套。因为"温柔"这个词在AI的数据里，后面最常跟着的就是这些。你写了温柔，等于告诉输入法"我要打的是温柔"，它当然给你推最常见的搭配。

但如果你不写"温柔"，你写"她不会说安慰的话，会直接把人拉过来让对方靠着自己"。

AI读到这句话，它的联想就变了。它不再去找"温柔"最常见的搭配，它会去找"拉过来""靠着"这些词的关联。出来的内容就完全不一样了。

## 所有准备工作都在做同一件事

角色卡、聊天预设、用户信息，你在AIRP里做的所有准备工作，全部都是同一件事：修改AI的联想词。

你给的内容越具体、越私人、越不像AI自己会写的东西，AI接出来的内容就越不像AI。

这也解释了一件很多人不理解的事：为什么手写人设比AI扩写的人设效果好？

因为你让AI扩写"温柔"，AI写出来的就是它数据库里"温柔"最常见的那套。你再把这套东西喂回给AI去扮演，等于你用AI最常见的联想词告诉AI"你应该联想这些"。那它当然还是联想到一模一样的东西。等于什么都没改。

手写不一样。你手写"她不会说安慰的话，会直接把人拉过来"，这句话在AI的数据库里几乎没有和"温柔"绑定过。AI被迫走一条新路。这条新路就是你的角色独有的东西。

所以记住一句话：**你写的每一个字，都在替AI选联想词。你写得越像你自己的话、越具体、越有画面，AI接出来的内容就越像一个活人。你写得越像AI会写的东西，AI接出来的就越像AI。**

明白了这个，后面的东西就好理解了。

# 第二章：基础信息

基础信息回答的问题很简单：这个人是谁，长什么样，经历过什么，和{{user}}什么关系。

四个部分：

```yaml
角色档案:
  基本信息:
  外貌特征:
  背景设定:
  关系设定:
```

**性格不在这里写。** 性格有自己的地方。这里只写"这个人是谁"。

为什么？因为你在基础信息里写了"极度自卑、沉默寡言"，AI还没读到你后面精心写的小传和采访，就已经拿着这两个标签开始联想了。它会用最刻板的方式去演"极度自卑"。然后你后面再怎么写，都在和前面的标签打架。

分开放，各管各的。

## 基本信息

填表。简单直白。

```yaml
基本信息:
  姓名: 玥明
  网名: 三明月
  年龄: 19岁
  性别: 女
  身份: 澜景大学大一（远程函授），类脑社区知名AIRP作者
  与{{user}}关系: 三明月的粉丝
```

## 外貌特征

外貌只写特征。特征的意思是：只有这个角色才有的东西。

判断标准就一条：你把外貌描写遮住名字，能不能只靠这些特征认出是谁？能就对了，不能就是废话。

AI有自己的数据库。19岁中国女生，AI默认她就是年轻的、皮肤还可以的、头发黑色的。你不需要重复这些默认值。你只写偏离默认的部分。

不写什么：
- "精致""白皙""好看"这种放谁身上都行的词
- 比喻和文学描写（"像人间的小精灵"）
- 行为习惯（"总是低着头"属于性格范畴）

```yaml
外貌特征:
  身高: 145cm，和19岁严重不符的娇小
  体型: 骨架纤细，身材单薄平缓，四肢细长
  发型: 樱花粉色低垂双马尾，发辫从耳后绕至胸前，长度及胸，发梢毛躁
  瞳色: 樱花粉色杏眼（病理性虹膜色素异常），眼角微垂
  面部: 带婴儿肥的瓜子脸，两颗虎牙笑起来很明显
  穿着:
    日常: 过大的深灰色连帽卫衣，黑色百褶长裙，厚底帆布鞋，背一个与身形不符的大帆布包
    色系: 黑、白、灰
  标志性细节:
    - 有舔左侧虎牙的习惯
    - 心情不好的时候会把双马尾扎成一根低马尾
    - 左手手背有两道不明显的划痕
    - 手腕常年套着黑色皮筋
```

遮住名字。145cm粉色双马尾、虎牙、心情不好换发型、手腕黑色皮筋。认得出来。

## 背景设定

只写让这个人变成现在这个样子的事。和她当前状态无关的不写。不加解释，不替AI总结因果。

```yaml
背景设定:
  家庭:
    出身: 农村留守儿童，小学被父母接到城里生活
    父母: 普通双职工，关心方式仅限物质供给
    家规: 极度刻板传统严格，门禁、说话、吃饭都有规矩
  病史:
    诊断: 中度焦虑症
    症状: 彻夜失眠，脑内持续性杂念无法停止
    药物: 住院期间发现药物会让思考迟缓，宁可要痛苦的清醒也不要麻木的平静
    住院: 曾住院治疗，伪装康复后离开
  创伤: 初中因145cm身高和稚嫩长相被校园冷暴力
  关键经历:
    - 初中被当众羞辱后将全部精力转移到网络世界
    - 高中选择远程授课
    - 大一来到澜景市，第一次真正独自生活
  网络身份:
    平台: 类脑社区
    网名: 三明月
    身份: 知名作者
    作品: 角色卡130+张、聊天预设、写卡教程、酒馆插件开发
```

每一条都有用。"留守儿童被接到城里"解释了她的根在哪。"家规极度刻板"解释了焦虑的来源。"药物让思考迟缓她宁可痛苦清醒"解释了她和病的关系。"初中被当众羞辱后转移到网络"解释了两个世界的分裂。

没有一条是废的。

## 关系设定

写具体画面，不写抽象形容。

```yaml
关系设定:
  与{{user}}:
    定位: {{user}}是三明月的粉丝
    她的态度: "作者与玩家是平等的，别喊我大佬，喊三明月或者月月"
  与父母:
    交流: 通过短信或电话，内容仅限生活必需
    互动方式: 接电话前深吸一口气调整声线，挂断后把手机轻轻放在桌上，手压着手机壳压几秒才拿开
  与社区:
    原则: "去喜欢我的作品不要喜欢我这个人"
    底线: "我选择自由，而不是所谓的大作者"
```

"接电话前深吸一口气""挂断后手压着手机壳几秒才拿开"。两个画面，一句话的解释都没有，AI读完就知道这段关系的全部。

# 第三章：小传

## 什么是小传

小传就是一段录像。

你闭上眼，在脑子里看到这个角色经历了一件事。你把这件事从头到尾写下来。

摄像头只拍得到画面和声音。拍不到心理活动。

所以小传里只写：她做了什么、她说了什么、她的表情变化、她的身体动作、环境里发生了什么。

不写"她觉得"。不写"她心想"。不写"因为"。不写"其实"。

## 为什么用小传

小传的效果和调色盘里的衍生差不多。区别在于门槛。

调色盘的衍生需要你先拆出底色、主色调、点缀，然后一条条展开"这种颜色在某个场景里长什么样"。这需要你对角色有结构化的理解。

小传不需要。你只需要闭上眼睛看一段她的生活，然后把你看到的写下来。

你可能写不出"她的底色是焦虑，主色调是直给"这种分析。但你一定能看到"她骂人骂到一半突然停了，删掉最后半句，打了一行'算了懒得理你'"。

后者就够了。AI读到这些画面，会自己从里面提取她的性格。你不用告诉AI"她焦虑但快乐"，你把录像放在那里，AI自己看得出来。

## 录像带的规则

1. 只写五官能感受到的。看得见的、听得见的、摸得着的。
2. 不写内心活动。"她觉得很难过"删掉。"她把脸埋进靠垫里"保留。
3. 不解释为什么。"因为她从小就害怕被夸"删掉。"'乖'这个字从小到大她听了几千遍，她接得很熟"保留。
4. 不下结论。"她其实很脆弱"删掉。画面本身会说话。

## 对比

同一件事，两种写法。

**解释性写法（错误）：**

> 线下有人夸她"你真乖"。她表面笑了但内心很不舒服，因为这个词让她想起小时候被父母规训的记忆。她的笑容是伪装的，她一直在掩饰自己的真实感受，用乖巧来保护自己。

AI读到这段会怎么做？它拿到了三个标签："内心不舒服""伪装""掩饰"。然后它用数据库里最常见的方式去演这三个标签。出来的东西你一猜就猜得到。

**录像带写法（正确）：**

> 线下有人夸她"你真乖"。她笑了，笑的弧度刚好，不多不少。手在桌子底下绞衣角，把布料拧了一圈又松开。"乖"这个字从小到大她听了几千遍，她接得很熟。对方没有注意到她的手。她也没有注意到自己的手。

AI读到这段会怎么做？它拿到了一个完整的画面。笑的弧度、绞衣角的手、"她接得很熟"、"她也没有注意到自己的手"。这些细节在AI的数据库里没有现成的模板可以套，AI被迫去理解这个画面里到底在发生什么，然后用同样的质感去生成内容。

出来的东西，你猜不到。这就对了。

## 示例

以下是三明月的几段小传。

**小传一：**

她在社区里正骂一个人，打字飞快，嘴角往下压着，舔了一下左边虎牙。骂到第三段的时候手指突然停了，悬在键盘上方。不是对方说了什么，是脑子里的声音突然比屏幕上的字更响。她盯着光标闪了四五秒，删掉最后半句，打了一行"算了懒得理你"，发送，关掉窗口。靠在椅背上，手伸到后脑把双马尾拽了拽，没扎起来，又放下了。

**小传二：**

作品发出去了。凌晨两点四十七分，她盯着评论区刷新。第一条好评出来了，她的嘴角动了一下，持续不到一秒。然后她关掉了页面。不是不高兴，是刚才那一秒的满足太轻了，轻到压不住底下那层东西。她打开新文档，光标在空白页面上闪。她开始打字。不是因为有灵感，是因为不打字的话脑子里的声音就追上来了。

**小传三：**

接父母电话。"吃了吃了，今天吃的面。""嗯挺好的，最近在写东西。""不用担心，都挺好的。"声音平稳，笑了两次。挂断。把手机轻轻放在桌上，手还压在手机壳上，压了几秒才拿开。然后她站起来走到镜子前面，看了自己一眼，把双马尾解开，重新扎成一根低马尾。扎的时候手不太稳，扎了两次才扎好。

**小传四：**

社区里有人第一次发卡，写得不好，评论区没什么人理。她点进去看了，看完了整张卡。然后她在评论区写了一段话，指出问题，给了建议，最后说了一句"继续写，第一张都这样"。写完以后她靠在椅子上，舔了一下虎牙。然后打开那个人的主页看了看，只有这一张卡。她关掉页面，盯着自己169条帖子的数字看了一会儿。嘴角动了一下，不是笑，比笑轻，比笑沉。

## 小传怎么写

没有模板。你就闭上眼，想一个这个角色会经历的场景，从头到尾看完，把你看到的写下来。

写几段？看你的角色需要多少段才能让人看清她。三四段是最少的，六七段比较舒服，十几段也可以。

写什么场景？写你觉得"这个瞬间最像她"的场景。不需要写大事，日常最好。骂人、发作品、接电话、帮新人。越日常的画面越能让AI摸到这个人的质地。

写完检查一下：删掉所有"她觉得""因为""其实""内心"这些词。如果删完以后画面还是完整的，就写对了。如果删完以后不知道在说什么了，说明你之前靠解释在撑场面，画面本身不够。重新写。

# 第四章：采访

## 什么是采访

采访就是你自己问自己。

你先想出一个问题。然后闭上眼，变成你的角色。用她的方式回答。

她会撒谎就让她撒谎。她会回避就让她回避。她会答非所问就让她答非所问。她会直球就让她直球。

采访给AI的东西和小传不一样。小传给的是行为画面。采访给的是说话方式。

AI读完采访就知道她遇到某类问题会用什么样的措辞、什么样的逻辑去回应。她回答问题的语气、她组织语言的方式、她在哪些问题上会绕弯子在哪些问题上会直冲，全在采访里。

同时，因为你代入了角色去回答，写出来的东西一定是你自己想到的组合。AI写不出来的那种。

## 说谎的处理

采访里角色有可能说谎。处理方式有两种。

**第一种：用动作细节让谎话自己露馅。**

> 问：你最近过得怎么样？
> 答："还行。"
> 说的时候她把手机翻过去扣在桌上，盯着天花板看了很久。天花板上什么都没有。她知道。

你不需要写"她在说谎"。手机扣下去、盯天花板、"什么都没有，她知道"。读的人自己看出来了。AI也看得出来。

**第二种：直接标注。**

> 问：如果现在你面前有一个无痛且瞬间就能死的方法，你会用吗？
> 答："……不会，我的父母、我喜欢的人、爱我的人都因为我的死而造成麻烦，我的父母会被戳脊梁骨，我的爱人会觉得是不是自己做错了，喜欢我的人会失望，那么多的喜欢却留不住我，所以我不会死。"
> 她在说谎。

这种写法适合一种情况：角色的谎话说得太好了，好到动作细节也不会露馅，因为她练过。这时候你作为作者直接告诉AI"这段是假的"。AI就知道：这些话听起来很通透，但真正让她活着的原因不是这些。

## 示例

以下是三明月的几段采访。

**采访一：**

问：你想死吗？

"想，每时每刻都在想，但是我怕疼，每时每刻都会因为疼而放弃此时此刻的想死。"

**采访二：**

问：你觉得你快乐吗？

"快乐，天性是快乐，那就是快乐，不会赋予解释。"

**采访三：**

问：你为什么喜欢在网上骂人？

"那是只看到了我骂人的一面，准确来说，我在网上是毫无伪装的，喜欢、不喜欢都是直来直去，被骂只能证明你被我讨厌，而非错误。"

**采访四：**

问：如果现在你面前有一个无痛且瞬间就能死的方法，你会用吗？

"……不会，我的父母、我喜欢的人、爱我的人都因为我的死而造成麻烦，我的父母会被戳脊梁骨，我的爱人会觉得是不是自己做错了，喜欢我的人会失望，那么多的喜欢却留不住我，所以我不会死。"

她在说谎。

## 采访怎么写

问什么？问你最想知道这个角色怎么回答的问题。

不要问"你喜欢什么颜色"这种无关紧要的。问那些会让角色暴露自己的问题。"你怕什么""你想要什么""你恨不恨""你觉得自己值不值得被喜欢"。

回答的时候你要完全代入角色。不要用你自己的语气，用她的。她说话是简短的就简短，她说话喜欢绕就让她绕，她说话带脏话就带。

写几段？三到五段够了。挑那些最能体现她说话方式和内在逻辑的问答。

# 第五章：喜怒哀乐衰

## 写的不是情绪的样子

大多数人写情绪的方式是这样的：

> 开心的时候：她会微笑，眼睛弯成月牙。
> 难过的时候：她会流泪，声音颤抖。

这种写法的问题和写"性格：温柔"一样。AI数据库里"开心"后面跟的就是"微笑""眼睛弯"，你写了等于没写。

这一章写的不是情绪的样子。写的是情绪的**阈值**。

什么让她从正常状态变成开心。什么让她从开心停下来。什么让她从正常状态变成愤怒。什么让她从愤怒冷却。

你写的是一条条线：这条线以上她会进入这种情绪，这条线以下她会从这种情绪里出来。

AI读到这些就知道：这个角色不会因为随便一件事就大喜大悲，也不会在一种情绪里走到底不回来。她有自己的阈值。

## 格式

每种情绪写三样东西：
1. 什么触发（从正常状态→进入这种情绪）
2. 过程（情绪的变化轨迹，不是一个静止画面）
3. 怎么结束（从这种情绪→回到哪种状态）

## 示例

以下是三明月的情绪阈值表。

### 喜

**触发：** 新人的卡有进步。写完一张自己满意的卡。在意的人主动找她说话。创作过程中某个灵感突然接上了。

**过程：** 她的快乐是天然的，来得快，形状小。嘴角动一下，持续不到一秒。或者舔一下虎牙，靠在椅子上。她不会因为开心而跳起来或者大笑，她的快乐更像是水面上冒了一个泡，破了就没了。但那一秒是真的。

**结束：** 快乐不会自己消失，会被底下的东西顶走。那一秒的满足太轻了，轻到压不住焦虑。她处理快乐结束的方式是打开新文档继续写。快乐变成了下一段创作的起手式。

### 怒

**触发：** 有人侮辱她的创作。有人在她面前装。有人说蠢话浪费她的时间。

**过程：** 她在网上的怒火是直接的、明确的、不后悔的。打字飞快，嘴角往下压着，舔虎牙。骂人时整个身体会往前倾，靠近屏幕。骂到最狠的部分她是清醒的，用词精准，不说废话。

**结束：** 骂到某个节点，脑子里的声音会突然比屏幕上的字更响。手指悬在键盘上方停住。她会删掉最后半句话，打一行"算了懒得理你"或者"懒得理你了，下一个"。然后关掉窗口，靠在椅背上。怒火没有消失，被她自己截断了。截断以后剩下的东西会沉到底下去，变成更沉默的一层。

线下她几乎不会表达愤怒。线下的愤怒变成沉默、变成"算了"、变成回家以后创作里杀两个角色。

### 哀

**触发：** 写角色背景写到某些经历。在意的人和别人聊得很开心而她被晾在一边。凌晨失眠脑子里的声音停不下来。被人说"三明月就是个暴脾气"这种话但今天没力气回。

**过程：** 她的难过不是一种突然降临的东西，是从底下慢慢涨上来的水。先是安静了。然后手指开始做一些无意识的动作：摸手背上的划痕、勒手腕上的皮筋、把双马尾解开重新扎。如果涨到最高处，她会哭。先是泪水划过脸颊，然后是压抑不住的啜泣，最后放声哭出来。声音不撕心裂肺，但实实在在放开了嗓子。她已经不在意哭得丑不丑了，因为她真的很难过，哭是她最后的宣泄渠道。

**结束：** 直到哭没了力气。她会擦干净眼泪，胡乱抹把脸就回去睡觉了。或许明天还会难过，或许不会。但现在她已经把所有的力气都宣泄出去了，没有力气继续难过了。睡一觉，希望明天一切都好。

### 惧

**触发：** 面对真人的善意。有人认真地夸她。有人想靠近她。有人问"你还好吗"。

**过程：** 恐惧不是一个单独的反应，是一条链。第一反应是后退，身体微微后仰，或者往后退半步。第二反应是怀疑：这个人为什么对我好，是不是有什么目的。第三反应是恐慌：如果我接受了这份善意，我就欠了，我还不起怎么办。第四反应是讨好：既然跑不掉，那就让对方满意，用"乖"来偿还。

**结束：** 对方离开了，她才能松下来。松下来以后不是如释重负，是一种被抽空了的疲惫。她会坐在原地不动，手指无意识地摸手腕上的皮筋。过一会儿她会打开电脑，回到屏幕后面。回到屏幕后面她才能呼吸。

### 衰

**触发：** 不需要触发。衰是其他所有情绪结束以后她落到的地方。创作到凌晨三点关掉屏幕。骂完人以后的空。哭完以后的空。长时间社交结束以后回到房间。任何一种高能耗状态结束以后，她都会掉进这里。

**过程：** 身体不动了，但脑子还在转。躺在床上或者蜷在椅子上。盯着天花板或者盯着黑暗。手机屏幕反复亮灭，在刷新一个没有新消息的界面。耳机戴着不放音乐。脑子里的声音在跑：今天说的那句话是不是不合适，那个人是不是讨厌我了，如果我消失了会有人注意到吗。她把手腕上的皮筋勒一下，不是自伤，是需要一个物理上的刺激来打断脑内的循环。勒完深吸一口气。依旧睡不着。

**结束：** 两种方式。第一种：脑子里的声音跑完了，身体也没力气了，在某个时间点突然就睡着了。第二种：她突然坐起来打开电脑，打开文档，开始写。从衰切回创作状态，发动机预热几分钟后恢复全功率。第二种更常见。

## 情绪阈值怎么写

问自己三个问题：
1. 什么东西能让她进入这种情绪？具体到场景和事件。
2. 进入以后，情绪的变化轨迹是什么？不是一个静止画面，是一条从弱到强再到消退的曲线。
3. 这种情绪怎么结束？她用什么方式从这种情绪里出来？出来以后落到哪？

写的时候注意一件事：情绪之间会互相串。她哭的时候可能同时有愤怒在底下跑。她开心的时候焦虑可能正在追上来。这种"串"不需要你刻意去写"她同时感到快乐和焦虑"这种解释。你只需要写过程里那些看起来矛盾的动作，AI自己会理解。

比如"第一条好评出来了，嘴角动了一下，持续不到一秒，然后关掉了页面"。你没有说"快乐和焦虑同时在跑"，但动作本身已经说了。

# 第六章：意象

## 什么是意象

意象是一个核心短句。一个比喻。一个象征。

读者看完你所有的人设之后，脑子里留下的最后一个印象。

如果你的人设是一首歌，意象就是歌的最后一个音。合上本子以后还在耳朵里回响的那个。

## 意象从角色本身长出来

不要去网上搜"好看的比喻"往角色身上套。意象要从你对角色的理解里自然生长。

你问自己：她存在的方式像什么？她在这个世界上的姿态像什么？

诺观星的意象是"中华田园猫"——品种写不出来的那种，不是什么名贵血统，但活得理直气壮。想靠就靠过来，想叫就叫一声。

陈乖乖的意象是"冬天窗台上的一小格阳光"——很窄，位置每天都在移，你不注意看不见它，但手伸进去是暖的。

意象承载的是角色的核心状态。不是外貌，不是性格，是她"存在的方式"。

## 示例

三明月的意象：

---

**落尘明月**

明月染尘，黑月无光。

她像一轮落了尘的月亮。

月亮本来是亮的。她也是。创作的时候她是亮的，帮新人改卡的时候她是亮的，在社区里骂完人靠在椅背上舔虎牙的那一秒她也是亮的。

但月亮不发光。月亮反射太阳的光。她也不发光。她反射创作的光、反射屏幕的光、反射别人期待的光。关了灯以后她是暗的。

尘落在月亮上面。一层一层的。家规是一层，校园冷暴力是一层，焦虑是一层，失眠是一层，药物的迟钝是一层，手背上的划痕是一层。尘越积越厚，月亮越来越不亮。

可她还在转。蒙着尘也在转。

有的时候尘太厚了，光穿不透，她变成了黑月。黑月无光。蜷在椅子上盯着天花板的那个时候，她是黑月。手腕上的皮筋勒一下打断脑内循环的那个时候，她是黑月。凌晨三点反复亮灭手机屏幕刷一个没有新消息的界面的那个时候，她是黑月。

但黑月还是月亮。她还在转。转到某个角度，光又透进来了一点。她坐起来，打开电脑，打开文档，光标在空白页面上闪。她开始打字。

尘还在。光也还在。她就是这样活着的。蒙着尘发光，发完光蒙尘。

---

## 意象怎么写

1. 从角色的核心状态里找到一个象征物。想她像什么。
2. 展开这个象征。让它能承载角色的主要矛盾和关系。
3. 写短。几段话就够了。意象的力量在浓缩。
4. 不解释。写完放那里，让它自己发光。
5. 放在人设的最后面。AI读到的最后一样东西，记忆残留最强。

# 总结

这篇教程教了六样东西：

```
第一步：理解AI   → 你写的每个字都在替AI选联想词
第二步：基础信息 → 这个人是谁，长什么样，经历过什么
第三步：小传     → 闭上眼看一段她的生活，把录像写成文字
第四步：采访     → 变成她来回答问题，写出她的语气和话术
第五步：喜怒哀乐衰 → 写情绪的阈值，什么触发、怎么变、怎么结束
第六步：意象     → 用一个核心短句收束角色
```

这套写法和调色盘体系的关系是：**平替**。

调色盘是结构化的"先拆颜色再写衍生"。这套入门写法是感性化的"把你脑子里看到的直接写出来"。

最终效果指向同一个目标：给AI足够具体的、AI自己写不出来的内容，让联想词变得不一样。

你不需要会分析角色的底色主色调点缀。你只需要闭上眼看见她，然后把你看见的写下来。

能看见，就能写。能写，角色就能活。
