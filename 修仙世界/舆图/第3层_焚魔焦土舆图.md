# 焚魔焦土舆图

## 提示词

中国古代舆图风格，修仙世界火山魔域地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"焚魔焦土舆图"六字，配暗红色火焰印章

整体色调炽热灼烧，以暗红、橙黄、墨黑为主色调，活火山群岩浆河纵横，烟雾弥漫热浪翻涌，在北原终年酷寒中唯一炎热之地

画面中央为焚天峰，最大活火山火山口喷发岩浆与火焰冲天，熔火之心堡垒嵌入火山内部炎魔一族核心，熔炉大厅在火山深处以剖面虚线标注红光透出

画面四周为三十余座大小活火山散布，火山锥熔岩台地地裂缝遍布，岩浆河如血管从焚天峰向四周辐射流淌七八条，最宽数十丈最窄几丈，部分河段凝固成黑色火山岩再重新涌出

画面下方为火山集市，外围火山群之间一片相对平坦的熔岩台地，露天集市散修商队冒险交易火属性材料

画面左下为岩浆矿道，焚天峰南麓矿区大量矿洞沿岩浆河分布，奴隶矿工在岩浆河边采矿身影渺小

画面上方为灰烬平原，北部被火山灰覆盖的平地寸草不生灰白色调，散修偶尔来此碰运气挖掘古物

画面右侧为冰火裂谷，东部边缘最大地裂一侧岩浆一侧冻土蒸汽终年不散，万禁教禁锢要塞沿裂谷而建黑色要塞坚固森严

边缘为冰火交界带，地表半冰半熔蒸汽弥漫能见度极低，色调从中央暗红橙黄向边缘渐变为灰白冰蓝

岩浆河以橙红色粗线标注流向，火山以红色三角标记喷发状态，热浪以橙色淡晕弥漫，整体宣纸质感泛焦黄灼烧痕迹，墨色浓烈如炭
