# 星辰山脉舆图

## 提示词

中国古代舆图风格，修仙世界星象符阵圣地地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"星辰山脉舆图"六字，配靛蓝色星纹印章

整体色调深邃神秘，以靛蓝、银白、暗紫为主色调，群峰耸立峰顶星光垂落，夜空星河璀璨符文闪烁

画面上方为玄天宗天枢峰，主峰峰顶观星阁冰晶卦盘日夜运转星光垂落，玉衡峰护山大阵寒梅照影阵眼光芒闪烁，天权峰执法堂思过崖肃穆庄严，星河秘境以星光漩涡标注，整体以靛蓝银白为主星象意境

画面下方为太虚宗，巨大浮空山悬浮于山脉上空殿宇由符文凝聚发出淡蓝光芒，符海流动液态符文平原金色符文如水波荡漾，阵枢殿居于浮空山中央，万符楼建筑本身是复合阵法符文密布墙面，试炼迷宫随机变化阵法光芒交错

画面左侧为天机城，修士交换情报的城池建筑精密如机关，情报阁占卜坊星象台林立

画面右侧为天工坊，立体城市正邪不拘，多层建筑悬浮半空以符文桥梁相连，炼器坊制符坊阵法坊层层叠叠，蒸汽与符光交织

画面下方为星落镇，山脉脚下小镇星光偶尔坠落如流星，镇中修士仰望星空

星光从天顶垂落如银色丝线连接各峰，符文以金色微光点缀全图，浮空山以虚影标注悬浮感，灵脉走向以星光细线标注，整体宣纸质感泛靛蓝如夜空，墨色深邃星辰点点
