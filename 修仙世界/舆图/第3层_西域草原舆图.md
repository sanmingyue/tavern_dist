# 西域草原舆图

## 提示词

中国古代舆图风格，修仙世界驭兽草原地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"西域草原舆图"六字，配赭色兽纹印章

整体色调辽阔豪迈，以赭石、草绿、天蓝为主色调，辽阔草原风吹草低灵兽遍野，民风彪悍天高地阔

画面中央为兽王山，雄踞草原中央山势雄浑，山中灵兽无数各类走兽飞禽隐现于山林之间，万兽山庄驯兽场在山腰开阔平地灵兽与修士共处，契约殿在山中殿宇古朴，兽魂塔高耸塔顶兽魂光芒闪烁

画面右侧为百兽城，西境主城坐落于草原中心地带，城池宏大城门宽阔可容灵兽通行，城内灵兽交易市场热闹非凡各方修士云集，灵兽幼崽拍卖场契约法器销售坊驭兽秘法交流堂，万兽山庄与苍澜国共管旗帜并列

画面左侧为苍澜城，草原西侧苍澜国都城，城墙坚固驭灵营驻扎旗帜飘扬，城内凡人与修士共居修真氛围浓厚，城外草原上骑兵与灵兽巡逻

草原辽阔以淡绿色铺底，灵兽群以小型图案散布草原各处奔跑嬉戏，风以淡色线条标注吹拂草浪，道路以赭色线连接三地，整体宣纸质感古朴，墨色豪放大气草原意境
