# 天脊中枢舆图

## 提示词

中国古代舆图风格，修仙世界正道核心地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"天脊中枢舆图"六字，配金色道纹印章

整体色调庄严肃穆，以石青、赭石、金色为主色调，天脊山脉群峰林立剑气道韵交织，灵气浓郁至极祥云缭绕

画面中央为天脊山脉主脉，主峰不周峰高不可攀直插天际云雾环绕峰顶不可见，群峰如剑戟林立气势磅礴，山脉横贯东西如大陆脊梁，险地葬妖谷风吼涧雷鸣顶以危险标记点缀山间

画面上方为天剑圣地，圣剑殿居于主脉之上金色殿宇辉煌庄严，殿内供奉神剑光芒冲天，天剑试炼场在殿前广阔平台剑气纵横，整体金色光晕笼罩

画面左侧为玉清道宫，推演殿古朴道观建筑群隐于山间，阵法传承阁藏经洞依山而建，道韵悠长仙鹤飞翔松柏苍翠，色调以青绿为主清幽出尘

画面右侧为万法宗，万法殿五行分殿环绕中央主殿，藏经万卷楼高耸入云，试炼百峰一百零八座山峰环绕排列如棋盘，各峰形态各异有的喷火有的结冰有的雷电交加，色调丰富五行色彩交织

画面下方为万象城，四方贸易枢纽城池宏大，四座城门朝向四方商队络绎不绝，城内坊市林立灵气充沛，是天脊中枢唯一的大型城镇

山脉间以栈道云桥相连，灵脉走向以金色细线标注，各宗门以对应旗帜标记剑旗道旗法旗，整体宣纸质感古朴，墨色浓淡相宜山水意境深远
