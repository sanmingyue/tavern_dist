# 东南暗域舆图

## 提示词

中国古代舆图风格，修仙世界正邪交错灰色地带地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"东南暗域舆图"六字，配暗红色毒纹印章

整体色调阴暗诡异，以暗红、墨绿、灰紫为主色调，正邪交错毒雾弥漫，唯童真谷一片生机

画面左上为赤魇沼，广袤沼泽地带水体暗红色弥漫剧毒瘴气，噬心殿盘踞其中百蛊池心毒魂毒尸蛊翻涌，噬魂林食人毒草密布阴森恐怖，炼毒渊毒液如湖色彩斑斓诡异，整体暗红毒雾笼罩

画面右上为童真谷，灵气充沛花草树木呈幼态生机勃勃，千年古木只三五丈高矮小可爱，归稚宗稚心峰山门建筑小巧精致如童话，归元殿归元泉碧绿清澈，百趣园色彩明快，逆生林万物逆向生长奇异景象，色调明亮翠绿与周围阴暗形成强烈反差如暗夜中的明珠

画面下方为玄渊城，玄渊盆地灰色城池鱼龙混杂，五大邪宗旗帜并列城门大开正邪魔妖各族修士皆可出入，城内黑市拍卖行雇佣悬赏各类灰色交易场所，街巷阴暗灯火昏黄

画面左下角标注泣血谷，蛊魔宗在神州的秘密据点终年血雾弥漫蛊虫横行，蛊血祭坛炼蛊窟血蛊牢笼以暗红虚线标注靠近南疆通道

毒雾以暗红紫色淡晕弥漫全图，童真谷以翠绿光晕隔绝毒雾，道路以灰色线标注曲折隐秘，整体宣纸质感泛暗做旧，墨色浓重阴郁
