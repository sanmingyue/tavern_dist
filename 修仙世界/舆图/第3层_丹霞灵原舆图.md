# 丹霞灵原舆图

## 提示词

中国古代舆图风格，修仙世界丹药灵草圣地地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"丹霞灵原舆图"六字，配赤色丹炉印章

整体色调温暖生机，西侧赤红东侧翠绿，丹火与灵草交相辉映

画面左侧为丹宗丹霞峰，九座丹炉状赤色山峰矗立喷涌丹香霞气，峰顶常年赤霞映天火光隐现，乾坤药圃小乾坤术开辟独立空间以虚线圆圈标注，百草堂大陆丹药交易中心建筑宏大，丹塔九十九层高耸入云层层叠叠，地火心宫在地下三千六百间炼丹室以剖面虚线标注，地火资源丰富赤色光芒从地底透出

画面右侧为百草庐，长春原四季如春翠竹灵树遍布生机盎然，万药园灵药培育分上中下三圃色彩斑斓百花争艳，医道堂白墙青瓦清净庄严，试药崖悬崖峭壁灵草攀援

画面下方左侧为百草集，药材铺丹炉阁医馆林立街巷飘散药香，散修采药人往来交易

画面下方右侧为常春城，药铺医馆林立城池翠绿环绕四季如春花木繁茂

丹香霞气以赤色淡晕从左侧弥漫，灵草生机以翠绿淡晕从右侧扩散，两色在中部交融，灵脉走向以金色细线标注，整体宣纸质感温润，墨色浓淡交替左赤右绿
