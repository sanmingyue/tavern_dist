# 南境水乡舆图

## 提示词

中国古代舆图风格，修仙世界水乡花海地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"南境水乡舆图"六字，配粉色莲花印章

整体色调温润柔美，以石青、淡粉、翠绿为主色调，湖光山色花海蝶舞，是中央神州最美的区域

画面左侧为并蒂湖，碧波万顷湖面辽阔，并蒂莲四季盛开粉白相间铺满湖面，莲心岛居于湖中央并蒂宫宫殿群倒映水面，映月殿水镜映照万里，双蕊阁配灵泉建筑精致，莲池秘境并蒂莲海幻境以虚线标注，纯阴灵力以淡紫色光晕笼罩湖面

画面右侧为蝶梦谷，终年蝶群纷飞万蝶翩翩色彩斑斓，花海烂漫百花盛开幻境与现实交织朦胧梦幻，化蝶峰山门居于谷中蝶变殿梦蝶池蝶舞坊建筑如蝶翼展开，色调以粉紫淡蓝为主梦幻迷离

画面下方为莲华镇，依并蒂湖东岸而建小桥流水白墙黛瓦，镇中商铺茶楼林立两宗弟子采买休闲之地，莲花灯笼高挂街巷

湖水与花瓣飘落全图，蝴蝶纹饰点缀四角，灵脉走向以淡粉色细线标注，整体宣纸质感细腻温润，墨色清淡水墨意境
