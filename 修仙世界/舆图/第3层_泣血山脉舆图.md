# 泣血山脉舆图

## 提示词

中国古代舆图风格，修仙世界血色矿脉山脉地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"泣血山脉舆图"六字，配暗红色血纹印章

整体色调暗红沉郁，以暗红、铁灰、血褐为主色调，山脉常年飘落暗红色血雪如同流血，血髓矿脉释放含铁灵气弥漫全图

画面为南北走向山脉绵延千里，山体呈暗红色含铁矿脉，暗红色血雪飘落覆盖山谷堆积厚厚红色雪层，血藤暗红色攀援植物缠绕山壁，铁骨树灰色坚硬乔木散布山间

画面中段为血崖堡，建于悬崖之上的黑色堡垒嗜血部落据点，堡垒粗犷坚固旗帜猎猎

画面中段偏下为血髓矿区，多个矿洞沿岩浆河分布矿工营地散布，矿洞入口暗红色光芒透出，矿工与奴隶劳作身影

画面下方为红雪谷，南段被血雪堆满的山谷相对安全，散修据点临时营地零星分布

画面中段偏上为啸血岭，一座被啸血狼群盘踞的山峰，狼群数量庞大上百头以兽影标注

北段靠近幽血门地界以虚线标注势力范围，中段各方势力交叉争夺最激烈，南段散修小型采矿团队活动

血雪以暗红色点状飘落全图，矿脉走向以暗红色粗线标注深入山体，危险等级以色调深浅从南到北加深，整体宣纸质感泛暗红做旧如血渍浸染，墨色浓重
