# 万剑山脉舆图

## 提示词

中国古代舆图风格，修仙世界剑道圣地地图，绢本设色，工笔山水，俯瞰视角，左上角以篆书题写"万剑山脉舆图"六字，配银色剑纹印章

整体色调冷峻锋利，以银灰、石青、金属光泽为主色调，剑气纵横千里金属性灵气弥漫，庚金剑气如丝如缕充盈画面

画面中央为万剑天池，碧水映剑光七十二座剑峰悬浮半空环绕天池形成万剑朝宗大阵，万丈石剑插入苍穹剑身银光闪烁，洗剑池天地灵液涤荡剑心碧波荡漾，论剑坪在天池畔开阔平台，藏经剑阁建于巨大裂隙之中玉简悬浮

画面阴面为剑冢，巨大山谷埋葬无数折断遗弃之飞剑，剑悲鸣之声日夜不绝，残剑插满谷地如荒凉墓场，色调灰暗悲壮

画面下方为剑鸣城，万剑山脉脚下巨城城墙高耸，城内修士十之八九皆为剑修剑气冲天，剑铺铸剑坊林立炉火通明锤声不绝，红尘酒家在城中一角酒旗飘扬超然中立

山脉以银灰色调为主金属质感，剑气以银色细线标注纵横交错，悬浮剑峰以虚影标注漂浮感，整体宣纸质感泛银灰，墨色锋利笔触如剑痕
