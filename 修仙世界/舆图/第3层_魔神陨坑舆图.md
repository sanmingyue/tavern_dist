# 魔神陨坑舆图

## 提示词

中国古代舆图风格，修仙世界域外禁地地图，绢本设色，工笔山水，俯瞰视角兼纵向剖面图，左上角以篆书题写"魔神陨坑舆图"六字，配深紫色混沌纹印章

整体色调深邃诡异，以深紫、墨黑、灰褐为主色调，混沌之气翻涌域外力量残留，最为阴森恐怖的禁地

画面采用俯瞰与剖面结合，上半部分为俯瞰天坑外原，下半部分为纵向剖面深入坑底

俯瞰部分为天坑外原，方圆数十里荒原寸草不生，地面散落暗色金属碎片域外陨铁闪烁异光，大地微微震颤以细密波纹标注，坑缘高出周围荒原数十丈撞击掀起泥土堆积如环形山

剖面部分自上而下四层，第一层天坑外原金丹期以上可活动散修矿工采集陨铁，第二层魔蚀坑壁坑壁陡峭嵌着暗紫色魔神骸骨碎片骨缝渗出混沌之气元婴期以上方可行动，第三层寂灭底渊坑底玄黑琉璃地面混沌之气浓到肉眼可见深紫色雾气翻涌魔神心脏化石居于底渊中央发出低频脉冲化神期以上方可进入，第四层虚空薄壁心脏化石正下方空间极薄微弱裂隙透出混沌虚空气息万禁教封印阵法以金色锁链纹标注合体期以上方可接近

坑内笼罩深紫色雾气浓度随深度递增，异界菌类苔藓深紫暗绿色点缀坑壁，混沌之气以深紫色漩涡纹弥漫全图，危险等级以色调深浅从外到内加深，整体宣纸质感泛深紫做旧如被混沌侵蚀，墨色浓重压抑
