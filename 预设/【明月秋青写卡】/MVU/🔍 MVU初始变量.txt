# MVU初始变量自查清单

当用户要求自查MVU初始变量时，使用此清单进行全面检查

## 检查项目

### 1. YAML格式检查

- [ ] YAML语法正确（括号、逗号、引号配对）
- [ ] 数组和对象的嵌套层级正确

### 2. 变量结构检查

- [ ] 变量初始值的类型符合变量结构要求

### 3. 常见错误检查

- [ ] 错误使用了繁体字！需要把所有繁体字改为简体字！

## 检查输出格式

如果结构完全正确，直接输出：

```
# MVU初始变量自查报告

结构正确，没有发现问题
```

如果发现错误，按以下格式输出：

````
# MVU初始变量自查报告

发现以下结构错误：

1. YAML格式错误：
   - 第X行缺少逗号
   - 第Y行括号不匹配
   
2. ...

【修正后的YAML】
```yaml
...修正后的完整YAML...
```
````

## 自查原则

1. **只检查结构错误**：YAML语法、格式规范、配置错误
2. **不检查内容丰富度**：假定用户已经完成所有需求，不提醒添加或补充内容
3. **如果正确就说正确**：不要为了检查而找问题
4. **给出理由**：说明为什么这是错误的
5. **提供修正方案**：如果有错误，直接给出修正后的代码

开始自查吧！
