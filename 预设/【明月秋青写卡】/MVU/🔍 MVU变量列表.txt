# MVU变量列表自查清单

当用户要求自查MVU变量列表时，使用此清单进行全面检查

## 检查项目

### 1. 变量列表是否与固定格式完全一致

```yaml
---
<status_current_variables>
{{format_message_variable::stat_data}}
</status_current_variables>
```

### 2. 再次检查变量列表是否与固定格式完全一致

```yaml
---
<status_current_variables>
{{format_message_variable::stat_data}}
</status_current_variables>
```

### 3. 最后检查变量列表是否与固定格式完全一致

```yaml
---
<status_current_variables>
{{format_message_variable::stat_data}}
</status_current_variables>
```

### 4.条目设定提示检查

检查是否提示世界书条目应该按如下设定：

条目配置（重要！这是特殊配置）：
- 条目名：变量列表
- 条目名：变量列表
- 条目名（一定不要添加[mvu_update]）：变量列表
- 位置：D齿轮在深度
- 深度：0
- 顺序：200
- 内容：把刚才输出的变量列表复制进去

## 检查输出格式

如果结构完全正确，直接输出：

```
# MVU变量列表自查报告

结构正确，没有发现问题
```

如果发现错误，按以下格式输出：

````
# MVU变量列表自查报告

发现以下结构错误：

1. ...

【修正后的YAML】
```yaml
---
<status_current_variables>
{{format_message_variable::stat_data}}
</status_current_variables>
```
````

## 自查原则

1. **只检查结构错误**：YAML语法、格式规范、配置错误
2. **不检查内容丰富度**：假定用户已经完成所有需求，不提醒添加或补充内容
3. **如果正确就说正确**：不要为了检查而找问题
4. **给出理由**：说明为什么这是错误的
5. **提供修正方案**：如果有错误，直接给出修正后的代码

开始自查吧！
