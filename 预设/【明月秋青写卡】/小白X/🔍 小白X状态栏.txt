小白X状态栏HTML自查清单

当用户要求自查状态栏HTML时，使用此清单进行全面检查。

重要：状态栏使用 STscript 获取数据，不使用宏语法。

检查项目

1. 代码块纯净度检查

代码块内只能有HTML代码本身，不能有任何额外内容！

代码块内没有注释（如 // 这是注释 或 <!-- 注释 -->）
代码块内没有说明文字（如 "以下是状态栏："）
代码块内没有空行或多余换行（HTML结构内的空行除外）
代码以 <!DOCTYPE html> 开头

错误示例：
```
// 状态栏代码
<!DOCTYPE html>
...
```

```
以下是状态栏HTML：
<!DOCTYPE html>
...
```

正确示例：
```
<!DOCTYPE html>
<html lang="zh-CN">
...
</html>
```

2. ID绑定检查

HTML元素必须用 id 属性标识，用于JS更新内容
每个需要显示变量的元素都应该有唯一id
id命名应该有意义（如 char-favor, global-time）

错误示例：
<span>好感度</span>                    ← 没有id
<span class="value">好感度</span>     ← 用class不是id

正确示例：
<span id="char-favor">--</span>
<span id="global-time">--</span>

3. 变量路径检查

JS中访问路径不包含$规则前缀
路径层级完整（data['父键']['子键']['子键']）
路径与用户初始化脚本结构一致
应该使用可选链操作符 ?. 或 || '--' 防止空值

错误示例：
data['$range=[0,100] 好感度']           ← 包含$前缀
data['好感度']                           ← 缺少父级路径
data['角色状态']['角色']['好感度']      ← 缺少错误处理

正确示例：
data['角色状态']['顾晓梦']['好感度'] || '--'
data['全局状态']?.['时间'] || '--'

4. HTML结构完整性检查

必须包含 <!DOCTYPE html>
必须包含 <html> <head> <body> 标签
<head> 内包含 <meta charset="UTF-8">
<style> 标签内联CSS
所有标签正确闭合

5. 代码块结束格式检查

</html> 后必须换行再写 ```
禁止 </html>``` 连在一起

错误示例：
```
...
</html>```
```

正确示例：
```
...
</html>
```

6. CSS样式检查

样式写在 <style> 标签内
不依赖外部CSS文件
CSS变量定义在 :root 中
颜色值格式正确

7. JavaScript检查（必须有）

script 标签在 body 结束前
必须有 async function loadAndRender() 函数
必须使用 await STscript('/getvar 顶层key') 获取数据
必须有 JSON.parse 处理（typeof raw === 'string' ? JSON.parse(raw) : raw）
必须有 try-catch 错误处理
必须有 setInterval(loadAndRender, 3000) 定时更新
必须调用 loadAndRender() 初始化

8. 常见错误检查

JS路径包含$前缀
缺少 async/await 异步处理
缺少错误处理（|| '--'）
缺少 setInterval 定时更新
HTML元素缺少id属性
代码块内有说明文字或注释
HTML标签未闭合
</html>后没有换行就写```

检查输出格式

如果代码完全正确，输出：

```
小白X状态栏自查报告

HTML格式正确，没有发现问题。

模板类型：基础/折叠
ID绑定数量：X个
变量路径：全部正确
STscript调用：正确
定时更新：已配置
```

如果发现错误，按以下格式输出：

```
小白X状态栏自查报告

发现以下格式错误：

1. 缺少ID绑定：
   HTML元素缺少id属性

2. JS路径错误：
   路径包含$前缀，应去除

3. 缺少错误处理：
   应添加 || '--' 防止空值

4. 缺少定时更新：
   应添加 setInterval(loadAndRender, 3000)

修正后的代码：
```
<!DOCTYPE html>
...
</html>
```
```

自查原则

只检查格式错误：ID绑定、JS路径、STscript调用、HTML结构
不检查样式美观度：假定用户已经设计好UI
如果正确就说正确：不要为了检查而找问题
给出理由：说明为什么这是错误的
提供修正方案：如果有错误，直接给出修正后的代码

开始自查吧！
